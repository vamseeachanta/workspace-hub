# Approved-claims library (shared reference + template)

Write claims **once**, clear them once, reuse everywhere — collateral, outreach, posts, and
registration forms all pull from here. Critical for a firm in recovery and essential for any
expert-witness lane (CV, profile, and collateral must be identical and verifiable).

Maintain the **actual filled library in the private engagement repo** (it contains specific
client/proof detail). This file is the structure + the rules; keep it PII-free in public.

## Structure
| Field | What it holds |
|-------|---------------|
| Credibility line | The one-sentence "who we are" (tenure, pedigree, accreditation) |
| Differentiators | What's genuinely different, in the buyer's terms |
| Proof points | Past performance, quantified outcomes, named methods/standards |
| Metrics | Numbers that are cleared to state externally |
| Testimonials | Attributable quotes (with permission) |
| Credentials | Licenses, fellowships, certifications, directory listings + expiry dates |
| Disclaimers | Required legal/scope wording |
| Per-segment angles | How the message bends for operators / EPCs / legal-insurance / renewables |

## Rules
- **Nothing external that isn't cleared.** If a claim isn't in the library as cleared, don't
  use it — and never invent numbers or imply work/relationships that don't exist.
- **Verifiable.** Every credential/metric must survive a procurement or opposing-counsel
  check. Keep the expert-witness CV and LinkedIn profile in exact sync.
- **Single source.** Collateral and outreach reference this library rather than re-writing
  claims, so wording and figures stay consistent.
- **Versioned.** When a claim changes (new project, expired credential), update here and
  the downstream assets that cite it.
