# Marketing/BD KPI spine (shared reference)

One **primary** metric per funnel stage; everything else is diagnostic. Used by
[`marketing-campaign-plan`](../marketing-campaign-plan/SKILL.md) (to set targets) and
[`bd-pipeline-review`](../bd-pipeline-review/SKILL.md) (to report).

| Stage | Primary KPI | Notes / benchmark posture |
|-------|-------------|---------------------------|
| Awareness | Impressions / reach | No reliable niche benchmark — track the trend |
| Engagement | Engagement rate (reactions + comments / impressions) | Directional only; technical/industrial B2B tends to engage above the cross-platform average — set your own baseline in month 1 |
| Followers | Net follower growth | No reliable external benchmark — absolute trend |
| Conversation | DMs / replies / form-fills / calls booked | Strong proxy for real interest, not vanity |
| Qualified | % of conversations matching ICP | Quality gate before counting a lead |
| Registrations / RFQs | # supplier portals live · # RFQs received | Absolute count — no benchmark |
| Won work | Opportunities won · win rate | Deal-size dependent; track internally |

## Rules
- **Every target needs a tracking mechanism** — name where the number is recorded and who
  updates it. A KPI with no owner/source is not a KPI.
- **Outcomes lead, vanity follows.** Conversations / registrations / RFQs / won work go at
  the top of any report; impressions/followers are leading indicators shown below.
- **Set your own baseline.** Public B2B/SaaS benchmarks are directional only — there is no
  reliable benchmark for a niche technical-services consultancy. Establish a month-1 baseline
  and manage to the trend.
- **Speed-to-lead matters.** Following up fast materially lifts qualified-conversion in
  general B2B data — make it an SLA, not an aspiration.
