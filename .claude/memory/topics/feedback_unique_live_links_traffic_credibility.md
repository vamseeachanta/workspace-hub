Each front-facing capability/skill should link to a **unique, purpose-built, publicly-indexable
live page** (its own URL), not a shared/generic "dashboards" section.

**Why:** uniqueness of each live link compounds into (1) more organic traffic — N distinct
indexed landing pages = N front doors, each titled with real specifics (field names, counts,
regions); and (2) credibility — a working live artifact per capability proves the work is real,
not a claim. Ten distinct live pages beat one shared dashboard.

**How to apply:** on the capabilities page (and any GTM surface), attach a distinct "► see it
live" link to every capability card, each pointing to its own page with a specific, self-explanatory
title. Don't strand live links in a separate generic section. Favour public reachability +
indexability. Applies to [[project_wed_capabilities_page]] and the
[[project_field_development_lifecycle_megaproject_poster]] per-field posters (each field page is
itself a unique credibility-building live link).
