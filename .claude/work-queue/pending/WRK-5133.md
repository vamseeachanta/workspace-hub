# gmsh Parametric Mesh Convergence Study Script

## Mission
Python script that sweeps element sizes, invokes gmsh mesh generation, tabulates element counts/quality metrics per size, and plots a convergence curve.

## Acceptance Criteria
- [ ] Accepts geometry + list of element sizes → runs mesh generation for each
- [ ] Tabulates: element count, min/max aspect ratio, mean Jacobian per size
- [ ] Outputs convergence data as YAML + optional matplotlib plot
- [ ] Works with box barge test geometry (known baseline)
- [ ] Graceful error for < 2 element sizes
