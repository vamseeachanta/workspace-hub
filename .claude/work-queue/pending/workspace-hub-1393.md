## Mission

Register Equinor ASA's Databricks marketplace as a data source for oil and gas data.

## Context

Equinor ASA publishes datasets on the Databricks marketplace at:
https://marketplace.databricks.com/provider/006d1a44-e5d8-4d20-8bd7-e9a311106007/Equinor-ASA

This should be catalogued in the worldenergydata repository as a known data provider.

## Scope

1. Catalog the Equinor ASA Databricks marketplace provider in data source registry
2. Document available datasets and access patterns
3. Evaluate dataset relevance to existing oil and gas data pipelines

## Acceptance Criteria

1. [ ] Equinor ASA Databricks marketplace added to data source registry
2. [ ] Available datasets documented with descriptions and formats
3. [ ] Integration notes for relevant datasets
