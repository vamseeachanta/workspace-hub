## Mission

Add the Equinor Northern Lights dataset as curated data in worldenergydata.

## Context

Equinor ASA publishes the Northern Lights dataset on the Databricks marketplace:
https://marketplace.databricks.com/details/ea296770-0ee0-4b74-a202-a2c0873add7c/Equinor-ASA_Northern-Lights

Northern Lights is a CO2 transport and storage project — relevant to CCS (carbon capture and storage) data.
This is part of the Equinor ASA provider (see WRK-1393 for provider registration).

## Scope

1. Download/access the Northern Lights dataset
2. Add to curated data catalog in worldenergydata
3. Document schema, provenance, and licensing

## Acceptance Criteria

1. [ ] Northern Lights data catalogued as curated dataset
2. [ ] Schema and data dictionary documented
3. [ ] Provenance and license terms recorded
