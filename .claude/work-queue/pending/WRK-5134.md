# gmsh OCC Boolean Workflow for Multi-Body STEP Assemblies

## Mission
Workflow script for importing multi-body STEP files, performing boolean union/cut/intersection via gmsh.model.occ, defeaturing, and exporting clean surface mesh.

## Acceptance Criteria
- [ ] Import multi-body STEP assembly → boolean union/cut
- [ ] Defeature small edges/faces below configurable tolerance
- [ ] Export watertight surface mesh (MSH, STL)
- [ ] Integration test with cylinder + appendage geometry
- [ ] Clear error message for corrupt STEP files
