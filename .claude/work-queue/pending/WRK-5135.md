# gmsh Boundary Layer Field Specification — y+ Targeting

## Mission
Module that computes first cell height from y+ target, generates geometric growth ratio, and creates gmsh BoundaryLayer field definition.

## Acceptance Criteria
- [ ] y_plus_to_cell_height(y_plus, Re, L, rho, mu) → first cell height
- [ ] create_boundary_layer_field(surfaces, hwall_n, ratio, thickness) → gmsh field ID
- [ ] Geometric growth: hwall_n * ratio^(n-1) for n layers
- [ ] Test with flat plate (known y+ analytical solution, y+=1 Re=1e6 → ~2e-5 m)
- [ ] Validation error for ratio < 1.0
