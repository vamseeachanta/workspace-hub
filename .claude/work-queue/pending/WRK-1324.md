## Mission

Fix the hook deadlock that prevents writing archive-tooling.yaml after close-item.sh completes.

## Bug

When a WRK reaches `done/` status (all 19 stages complete), `enforce-stage-machinery.sh` blocks
all Write/Edit to `evidence/` directories because no stage is `in_progress`. But `archive-item.sh`
requires `evidence/archive-tooling.yaml` to exist before archiving. `enforce-no-bash-evidence.sh`
also blocks Bash cp/mv to evidence dirs.

Result: deadlock — archive-tooling.yaml cannot be written by any tool.

## Fix Options

1. Add exception in enforce-stage-machinery.sh for `archive-tooling.yaml` filename
2. Add exception when all stages are `done` (WRK is in done/ or archive/)
3. Have close-item.sh auto-generate archive-tooling.yaml before marking all stages done
