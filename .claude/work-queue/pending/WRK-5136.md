# gmsh Mesh Quality Gate Script with YAML Verdict

## Mission
Standalone quality gate script with configurable thresholds that outputs YAML pass/fail verdict — usable as pre-solver gate.

## Acceptance Criteria
- [ ] Accepts mesh file + threshold config → evaluates all elements
- [ ] Outputs YAML verdict: {pass: bool, metrics: {...}, threshold_violations: [...]}
- [ ] Default thresholds: aspect ratio <10, skewness <0.85, min Jacobian >0.3
- [ ] CLI entry point: python -m digitalmodel.solvers.gmsh_meshing.quality_gate mesh.msh --config thresholds.yaml
- [ ] Integration test with known-good and known-bad meshes
- [ ] Update gmsh-meshing quality-metrics SKILL.md with automation section
