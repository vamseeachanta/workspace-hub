# WRK-5124: Stage 6 cross-review stalls in Stage 5 gate check for Codex/Gemini

## Problem

The Stage 6 cross-review runner stalls in the Stage 5 gate check path before it launches
Codex/Gemini review submission. The failure is **not** that Codex can't see the scripts — it can.

### Root Cause (verified via process tree)

`cross-review.sh` was sitting under `verify-gate-evidence.py --stage5-check ...`, **not** inside
`submit-to-codex.sh`. The process never reaches provider submission.

### Why Claude works but Codex/Gemini don't

- **Claude**: its environment successfully gets through the gate/runner path
- **Codex/Gemini**: getting stuck in the local workflow gate / `uv` execution path before
  provider review starts — not blocked by missing scripts

## Investigation Needed

1. Trace `verify-gate-evidence.py --stage5-check` to find why it hangs for non-Claude providers
2. Check if `uv` execution path differs between Claude and Codex/Gemini environments
3. Determine if this is a gate evidence format issue or an environment/path issue

- [x] Stage 6 cross-review successfully launches for Codex provider
- [x] Stage 6 cross-review successfully launches for Gemini provider
