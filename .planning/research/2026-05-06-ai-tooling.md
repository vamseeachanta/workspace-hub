## Key Findings

- **Claude Code May 2026: Ultrareview [RESEARCH PREVIEW] launches automated cloud bug-hunting with findings routed back to CLI/Desktop; automatic session recaps on terminal return; broader plugin support (--plugin-dir accepts .zip archives), improved MCP handling (tool count reporting, stdio argument corruption fix). Agent Teams feature shipped (public, not experimental).** Ultrareview is the production counterpart to April's Ultraplan — cloud-based review agents (bug hunting, code quality) mirror April's cloud planning agents (task orchestration). Automatic session recaps solve context restoration at session boundaries (workspace-hub multi-machine Phase 7 continuity). Plugin ecosystem maturity (zip support, custom themes) enables Phase 7 orchestrator plugins (custom task dispatch visualizations). No breaking changes from April releases; Phase 7 execution stability maintained.

- **GSD v1.39.0 + v1.40.0 (May 2026): v1.39 ships --minimal install flag (cold-start overhead reduced ~95%: 12k tokens → 700 tokens, ideal for local/resource-constrained agents), /gsd-edit-phase command (non-disruptive phase editing without number/position changes), post-merge build & test auto-detection (Xcode/Makefile/Justfile/Cargo/Go/Python/npm patterns recognized automatically). Skill surface consolidated from 86 → 59 entries (grouped skills, zero functional loss). v1.40 promotes six namespace meta-skills as first-stage routers (hierarchical skill dispatch to keep eager skill listing token cost low). Namespace routing pattern = production standard for Phase 7 multi-agent skill discovery (orchestrator queries namespace router, routes to specific skill).** GSD v1.40 namespace meta-skills directly enable Phase 7 orchestration pattern: top-level namespace queries (e.g., "orchestration" → routes to /gsd:phase-dispatch, /gsd:solver-invoke, /gsd:result-aggregate). Skill consolidation (86 → 59) + namespace routing = context efficiency at 50+ skill catalog scale. --minimal install enables Phase 7 sub-agents on dev-secondary/licensed-win-2 (constrained context budgets; orchestrator dispatches lightweight agents running --minimal GSD).

- **MCP stateless HTTP spec (June 2026 publication, SEPs finalizing Q1 2026 confirmed on-track): Reorients around independent stateless requests (no sticky sessions, no distributed session stores). Initialize handshake eliminated; shared information sent with each request/response. Sessions moved to data model layer (cookie-like mechanism proposed to decouple session state from transport). Discovery mechanism for clients to query server capabilities (UI hydration use cases). Goal: horizontal scaling without session affinity, resilience to server restarts, deployment simplicity behind load balancers/proxies.** Validation: May 2026 search confirms June 2026 publication timeline remains on-track (no delay signals). Stateless HTTP ships post-Phase 7 execution (mid-May Phase 7 target, June spec publication 2-3 weeks after). Phase 7 uses current SSE transport (stable); Phase 7.1 can adopt stateless after June spec stabilization (Q3 implementation window). Cookie-like session mechanism (explicit rather than implicit) matches workspace-hub pattern of explicit task boundaries + mailbox polling (Phase 7 orchestrator design already anticipates this pattern).

- **Codex CLI May 2026 sandbox hardening: Deny-read glob policies for fine-grained filesystem isolation, custom permission profiles (sandbox CLI profile selection, cwd controls, active-profile metadata), Windows native sandbox + WSL integration tightened (PTY edge cases, elevated runner process handling, pseudoconsole startup validation). Security-sensitive flows: logout revokes managed ChatGPT tokens, project hooks + exec policies require trust. Secure devcontainer profile with bubblewrap support (macOS sandbox allowlists for Unix sockets).** Codex CLI hardening (deny-read globs + custom permission profiles + Windows AppContainer enforcement) represents maturation toward Phase 7.1 multi-machine solver sandboxing. If licensed-win-2 joins Phase 7.1 solver pool, Codex CLI deny-read policies enable isolation (solver agent cannot read client confidential data in shared workspace, only OrcFxAPI inputs/outputs). May security updates close permission management gaps (active-profile metadata enables Phase 7 agents to query permitted filesystem scope, reducing over-permissioning risks).

- **Claude Code Agent Teams production validation extended: Memory for Managed Agents (public beta, May 2026) delivers cross-session learning with filesystem-based memories; agents learn from every session. Intelligence-optimized memory layer balances performance with flexibility. Agent Teams feature is now public (not experimental). Anthropic agentic coding trends report (May 2026) profiles agent adoption patterns across enterprise. Opus 4.7 is shipping default; May 2026 releases show no regressions in agent coordination patterns validated at Anthropic scale in prior research (February 2026: 16-agent teams, 54% PR review coverage).** Memory for Managed Agents (now in public beta) enables Phase 7 + Phase 7.1 agents to learn from execution traces across sessions (incident-to-test conversion formalized, agent self-improvement). Agent Teams moving from experimental to public signals production maturity. May 2026 trends report provides market validation (agents reshaping coding practices enterprise-wide); positions workspace-hub Phase 7 as aligned with mainstream infrastructure patterns (not early-adopter risk).
