# Research: standards — 2026-05-11

## Key Findings

- **API 2RD (Dynamic Risers for Floating Production Systems), 3rd edition (late 2025) — now in active deployment** — Incorporates advances in riser integrity management for deepwater applications (spars, semi-submersibles, tension leg platforms). Enhanced clarity on design loads, acceptance criteria, and material grading. Directly applicable to workspace-hub Phase 1 mooring_design.py (cathodic protection, dynamic riser analysis) and Phase 7 OrcaWave solver integration (riser load cases for vessel analysis).

- **ISO 15589-2:2024 (Cathodic protection of pipeline transportation systems — Offshore pipelines)** — Recently published with emphasis on offshore pipeline CP design. Complements DNV-RP-B401 + NORSOK M-503 anode spacing rules. Relevant to Phase 1 mooring_design.py CP module (anode spacing ≤ 200m validation, 2x factor near platforms) and Phase 1.1 client deliverables requiring multi-standard CP traceability.

- **ABS Consolidated Offshore Rules (effective January 1, 2025 → 2026 notices released) — New In-Service Inspection Plan (ISIP) + Structural Critical Inspection Point (SCIP) requirements effective 2026** — Consolidated ruleset simplifies classification but tightens structural assessment requirements. January 2026 notices document material grade acceptance, geometry limits, and fitness-for-service qualification criteria. Relevant if Phase 1.1 clients require ABS class certification (especially Gulf of Mexico + Asia operators).

- **API 579-1/ASME FFS-1 Part 16 (Fiber Reinforced Polymer equipment assessments) — targeting 2026 technical release, WRC Bulletin 601 foundation published** — New material coverage extends FFS methodology beyond traditional steel structures to composite risers, subsea components, and pressure equipment. Directly applicable to Phase 999.2 backlog (fitness-for-service domain expansion) and emerging Phase 1.1 client engagements with composite subsea structures (increasingly common in deepwater).

- **DNV-RP-C203 (Fatigue Design of Offshore Steel Structures) April 2023 revision remains current — no 2026 update announced** — Covers jacket, riser, pipeline, and floating production vessel fatigue assessment. Validates Phase 1 spectral_fatigue.py module (shipped March 2026 with DNV-RP-C203 April 2023 compliance) as standards-current through 2026-2027.

`★ Insight ─────────────────────────────────────`

**May 11, 2026 standards landscape reveals three key findings for Phase 7 execution (mid-May target) and Phase 1.1 planning (late May execution):**

**1. Phase 1 Modules (Shipped March 2026) Remain Standards-Current — No Retrofit Pressure**

DNV-RP-C203 April 2023 (fatigue) is stable through 2026-2027 with no announced revision. NORSOK M-503 Rev. 2 anode spacing rules (mooring_design.py CP module) validated by new ISO 15589-2:2024 (complements, does not contradict). API 2RD 3rd edition (late 2025) postdates Phase 1 shipping but represents evolution, not breaking change (same fundamental load case approach). Phase 1 modules are compliant with current/near-current standards baseline. **Phase 7 execution mid-May proceeds without Phase 1 retrofit pressure.**

**2. API 2RD 3rd Edition + ISO 15589-2:2024 Signal Phase 1.1 Client Validation Gates**

API 2RD 3rd ed. introduces explicit design load traceability (dynamic, fatigue, hydrostatic) + material grading requirements. ISO 15589-2:2024 provides ISO-harmonized CP methodology (multi-jurisdictional compliance signal). Combined effect: Phase 1.1 client deliverables should cite dual/triple standards (API + ISO + NORSOK) for riser analysis + CP design projects. This is not new technical requirement — it's formalization of validation gates (standards checklist as passing criteria for client acceptance). **Phase 1.1 planning (late May) adds "API 2RD 3rd ed. citation" + "ISO 15589-2:2024 anode spacing validation" to client acceptance checklist (non-blocking for Phase 7).**

**3. ABS Consolidated Rules (2026 Notices) + API 579 Part 16 (Summer 2026) = Conditional Future Expansion**

ABS 2026 notices (ISIP/SCIP tightening) and API 579 Part 16 (composite FFS, June-July target) are both conditional future decisions: (1) ABS retrofit needed only if Phase 1.1 client requires ABS classification (not current scope unless GOM/Asia client lands), (2) Part 16 composite scope needed only if Phase 1.1 client engages composite subsea structures (emerging market trend, not blocking Phase 7). **Phase 7 execution unaffected. Phase 1.1 planning gates both decisions: "ABS required?" (triggers Phase 1.2+ retrofit), "Composite structures?" (triggers Phase 999.2 scope expansion post-Part-16-publication).**

**Combined insight:** May 11, 2026 standards ecosystem shows **Phase 7 readiness with established Phase 1.1 validation gates**. No blockers for Phase 7 mid-May execution. Phase 1.1 validation (late May) operates within well-defined standards baselines (DNV-RP-C203, NORSOK M-503, API 2RD, ISO 15589-2).
