# Research: standards — 2026-05-18

## Key Findings

- **ISO 15589-2:2024 published February 2024 (Edition 3) — offshore pipeline cathodic protection harmonization** — Supersedes ISO 15589-2:2012 with revised coating breakdown factors, expanded anode utilization factors, and updated anode compositions aligned to current industry practices. Covers carbon steel, stainless steel, and flexible metallic pipelines; includes subsea production/injection equipment. Directly applicable to Phase 1 `mooring_design.py` CP module and Phase 1.1 client deliverables requiring multi-standard CP traceability (ISO + NORSOK + DNV-RP-B401 hierarchy).

- **API Standard 2RD 3rd Edition (late 2025) — dynamic risers for floating production systems with enhanced integrity management** — Unifies design methods from earlier editions, introduces strengthened robustness requirements (test against extreme environmental conditions beyond normal operations), and provides explicit guidance for riser reassessment coordination with API RP 2RIM (Riser Integrity Management). Key advance: reduced design method confusion (unified load measurement approach), improved clarity for permitting, and catastrophic-failure prevention via repair-before-failure design philosophy. Applicable to Phase 1 mooring design (dynamic riser load cases) and Phase 7 OrcaWave (if vessel hull analysis includes riser hydrodynamic loads).

- **ABS Rules 2026 (effective January 1, 2026 onward) — ISIP/SCIP structural inspection critical points** — New In-Service Inspection Plan (ISIP) and Structural Critical Inspection Point (SCIP) requirements formalized in sections OR 7C-2-1/25, 27, and OR 7C-2-3/2. Special surveys now require ISIP status verification with RBI (Risk-Based Inspection) plan approval enabling ABS notation issuance for compliant assets. Applicable to Phase 1.1 client structural assessments if ABS classification required (Gulf of Mexico, Asia operators); conditional on client scope.

- **API 579-1/ASME FFS-1 Part 16 (FRP Composite Fitness-For-Service) — consensus standard in development, expected 2026 publication** — ASME/API Fitness-For-Service Joint Committee developing standardized assessment methodology for composite materials. WRC Bulletin 601 (May 2023, 4th edition) provides technical foundation. Will introduce tiered assessment levels (simple to complex) consistent with existing API 579 steel equipment methodology. Critical gap closure: no agreed-upon standard currently exists for FRP in-service integrity assessment. Phase 999.2 backlog (fitness-for-service domain expansion) directly benefits from this standard when published.

- **DNV standards ecosystem stable through 2026-2027 — DNV-RP-C203 (fatigue, April 2023) and DNV-RP-B401 (CP design) remain current** — No announced 2026 revisions to DNV-RP-C203 (offshore steel fatigue) or DNV-RP-B401 (cathodic protection design); standards validate Phase 1 module compliance without retrofit pressure. DNV-RP-F103 (submarine pipeline CP) and DNV-RP-0416 (subsea systems) referenced alongside NORSOK standards in current practice.

**May 18, 2026 standards landscape confirms Phase 7 execution readiness with formalized Phase 1.1 validation gates — no retrofit pressure, no blockers, three conditional future expansions.**

**Three key patterns across five recent standards findings:**

**1. Phase 1 Modules (Shipped March 2026) Remain Standards-Current — Zero Retrofit Urgency for Phase 7**

DNV-RP-C203 April 2023 (fatigue) stable through 2026-2027 with no announced revision. **2. Recent Standards Updates Formalize Phase 1.1 Client Acceptance Gates — Not Technical Requirements**

ISO 15589-2:2024, API 2RD 3rd ed., ABS 2026 ISIP/SCIP notices, and API 579 Part 16 all represent **formalization of existing industry practices into agreed standards**, not revolutionary technical advances. Immediate implication: **Phase 1.1 client deliverables (late May 2026) should cite these standards in multi-standard traceability checklists (validation gates for audit defensibility), not deep technical refactors.** Example: CP design report cites ISO 15589-2:2024 (primary), NORSOK M-503 Rev. 2 (Norwegian compliance), DNV-RP-B401 (subsea specialist). Riser design report cites API 2RD 3rd ed. (unified design method), DNV-RP-C203 (fatigue), accepted criteria checklist. **These are client acceptance gates formalized, not code changes required.**
