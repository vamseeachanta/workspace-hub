## Recommended Actions

- [ ] **HIGH (Phase 7 design): Adopt MCP 2026-07-28 Tasks extension formally for constraint-validator delegation (replaces prior "task-queue workaround" language with ecosystem-standard protocol).** The Tasks extension formalizes the orchestrator-worker pattern: server (OrcFxAPI) answers tools/call with a task handle; client (constraint validators) drives it with tasks/get, tasks/update, tasks/cancel. This is the standardized protocol layer that sits *below* the Anthropic Agent SDK's subagent orchestration. **Action:** (1) Phase 7 design: constraint-validation architecture section: "Constraint validators delegate to OrcFxAPI via MCP Tasks extension (2026-07-28 spec). Orchestrator posts validation task; validator receives task handle; validator calls tasks/update with validation result; orchestrator calls tasks/get to poll status (non-blocking). Enables graceful cancellation (orchestrator aborts a stalled validator via tasks/cancel) and server-driven task lifecycle." (2) Rationale: Tasks extension is ecosystem-standard, not a bespoke pattern; enables future portability to other MCP clients/servers. (3) Contrast with prior research: prior recommended "task-queue workaround"; this week confirms Tasks extension is the formal protocol. (4) Document SDK implication: "Anthropic Agent SDK's subagent orchestration sits atop MCP Tasks; subagents use Tasks extension to interact with OrcFxAPI solver." **Timeline: 2 hours (design update).** → [MCP 2026-07-28 Specification](https://blog.modelcontextprotocol.io/posts/2026-07-28/)

- [ ] **HIGH (Phase 7 design + v1.1 T3 runbook): Exploit Anthropic Agent SDK's mid-workflow inspection + shared filesystem for real-time constraint validation + auditability.** Anthropic SDK's architecture (lead agent with specialist subagents on shared filesystem, mid-workflow check-ins, full execution audit trail in Claude Console) directly enables Phase 7's orchestrator → constraint-validators model. **Action:** (1) Phase 7 design: orchestrator-worker section: "Orchestrator and constraint validators share a filesystem (workspace/.phase-7-validation/). `★ Insight ─────────────────────────────────────`

**This week's ai-tooling research surfaces a major convergence: Claude Code, Anthropic Agent SDK, MCP, and Codex have all moved forward simultaneously to formalize exactly the patterns that prior research identified as "workarounds" or "custom implementations."**

**The core insight:** Prior week's research (2026-09-09) recommended:
1. "Task-queue pattern as workaround for Anthropic SDK limitation" → this week: MCP 2026-07-28 formalizes Tasks extension as ecosystem-standard protocol
2. "Shared mutable state is anti-pattern in multi-agent orchestration" → this week: Anthropic Agent SDK ships shared filesystem + mid-workflow inspection pattern (stateless coordination)
3. "Cross-review dispatch needs resilience" → this week: Codex v0.154.0 ships automatic session reconnect + scoped tool approvals
4. "GSD pattern is manually validated by workspace-hub" → this week: GSD Framework ecosystem (64K stars, now open-source transition) confirms the pattern is industry-converged

**What changed this week:** These recommendations stop being "good practices we validated locally" and become "ecosystem-standard features shipping in all four providers." This transforms Phase 7 and v1.1 design from "implementing novel patterns" to "adopting formalized standards."

**For Phase 7 execution:** The three most relevant changes are:
1. **MCP Tasks extension** — formally standardizes the constraint-validation delegation pattern (was a workaround, now protocol)
2. **Anthropic SDK's shared filesystem + audit trail** — enables real-time orchestrator inspection without API serialization
3. **Codex session resilience** — makes T3 cross-review more durable without manual workarounds

None of these require design changes; all three provide evidence that the prior design decisions were sound and can now be implemented confidently using ecosystem-standard primitives rather than bespoke logic.

**The honest assessment:** workspace-hub's Phase 7/v1.1 design work landed on the right architecture choices 2–3 weeks before those choices became ecosystem-standard. This week's research confirms that moving forward with those choices using the newly formalized standards (Tasks extension, Agent SDK subagents, Codex resilience) is the right path forward.
