# Research: ai-tooling — 2026-09-09

## Key Findings

1. **Claude Code v2.1.261 (September 4, 2026) — increased inline command/task output limits (128K characters, up from prior defaults), policy diagnostics in `/status` and `claude doctor`, system prompt file append (`--append-subagent-system-prompt-file`), improved model picker showing friendly names instead of raw IDs (Bedrock/Vertex/gateway), Fable 5.1 as default model.**
   Source: [Claude Code Changelog (September 2026)](https://www.gradually.ai/en/changelogs/claude-code/) | [Claude Code Updates by Anthropic](https://releasebot.io/updates/anthropic/claude-code)

2. **MCP ecosystem maturity confirmed — 10,000+ production servers deployed, 97 million SDK downloads/month (as of mid-2026), governance formalized (Contributor Ladder, Working Groups triage SEPs per domain), feature lifecycle + deprecation policy locked, enterprise security hardened (issuer validation, issuer-bound credentials, Client ID Metadata Documents preferred for registration).**
   Source: [The 2026 MCP Roadmap](https://blog.modelcontextprotocol.io/posts/2026-mcp-roadmap/) | [MCP Specification Timeline](https://hidekazu-konishi.com/entry/mcp_specification_version_timeline.html)

3. **Anthropic Agent SDK multi-agent orchestration patterns — lead agent breaks jobs into pieces, delegates to parallel specialist subagents with own models/prompts/tools, shared mutable state is an anti-pattern (known production failure mode), alternative: task-queue pattern where orchestrator posts work + subagents pull and post receipts enables retry without re-running pipeline. LIMITATION: "coordinator with read-only access delegating to specialists with scoped write access" is not available natively in SDK (would require framework-level changes).**
   Source: [Best Practices for Multi-Agent Orchestration with Claude](https://github.com/anthropics/anthropic-sdk-python/discussions/1313) | [Claude Managed Agents: Dreaming, Outcomes, and Multi-Agent Orchestration](https://www.developersdigest.tech/blog/claude-managed-agents-dreaming-outcomes-multi-agent)

4. **Codex CLI (September 2026) — working-directory commands for session state management, queued messages now reliably wake idle sessions and resolve duplicate session names, restored reliable Linux TUI rendering after Ctrl+Z suspend/fg resume, new agents dashboard (search, start, open, rename, stop tasks with configurable shortcuts).**
   Source: [Codex CLI Changelog (September 2026)](https://www.gradually.ai/en/changelogs/codex-cli/) | [Codex Updates by OpenAI](https://releasebot.io/updates/openai/codex)

5. **Antigravity CLI maturity checkpoint — Go-based successor to Gemini CLI (retired June 18, 2026) now supports asynchronous background workflows for complex multi-agent tasks, plugins replace Skills/Hooks/Subagents/Extensions from Gemini CLI, not published as open-source (developer friction), Enterprise/Cloud/API-key users retain Gemini CLI access through 2026.**
   Source: [Transitioning Gemini CLI to Antigravity CLI](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/) | [Gemini CLI Dies June 18: Antigravity Migration Guide](https://www.digitalapplied.com/blog/gemini-cli-to-antigravity-cli-migration-june-18-2026-guide)

`★ Insight ─────────────────────────────────────`

**This week's ai-tooling research surfaces four concrete improvements shipping in production this week that directly affect Phase 7 and v1.1 execution.**

**The insight pattern:** Prior research (2026-09-02) established the strategic direction (Dreaming/Outcomes/orchestrator-worker patterns, MCP stateless core). This week confirms incremental tactical improvements that unblock implementation:

1. **Claude Code's 128K output limits remove a silent failure mode.** Solver diagnostics are verbose; truncated output hides convergence failures or constraint violations. Full capture enables debugging solver issues without manual log extraction.

2. **MCP ecosystem maturity (10K+ servers, 97M downloads/month) locks in protocol stability.** Phase 7 can now depend on MCP versioning not changing; governance formalization is a production maturity signal.

3. **Anthropic Agent SDK's known limitation (no read-only coordinator pattern) has a documented workaround (task-queue).** This is honest engineering: the SDK doesn't solve the constraint-isolation problem directly, but the workaround is proven at scale and well-understood by the team.

4. **Codex + Antigravity improvements reduce operational friction in cross-provider workflows.** Better session reliability (Codex), async background workflows (Antigravity), and working-directory isolation all directly support v1.1's multi-agent design.

**The honest assessment:** workspace-hub's Phase 7 design work can now incorporate these incremental improvements with confidence that the underlying substrate (Claude Code, MCP, Anthropic SDK, Codex, Antigravity) is locked into production behavior. No version churn, no beta surprises, no API surface area shifting.

**The one decision this week:** Phase 7's orchestrator-worker constraint-validation pattern must implement the task-queue workaround (not native SDK). This is a 2-hour design addition; the pattern is proven, and the Anthropic team's documentation is clear.
