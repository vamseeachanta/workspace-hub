  <action>
    This task requires physical/RDP access to licensed-win-1 (Windows machine) to enable OpenSSH Server and verify software prerequisites. Claude cannot SSH to a machine where SSH is not yet enabled.

    User must perform the following on licensed-win-1 via RDP or physical access, in an **Administrator PowerShell**:

    **1. Enable OpenSSH Server:**
    ```powershell
    Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0
    Start-Service sshd
    Set-Service -Name sshd -StartupType 'Automatic'
    ```

    **2. Set default shell to PowerShell** (prevents cmd.exe issues per Pitfall 2 in RESEARCH.md):
    ```powershell
    New-ItemProperty -Path "HKLM:\SOFTWARE\OpenSSH" -Name DefaultShell -Value "C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe" -PropertyType String -Force
    ```

    **3. Firewall rule:**
    ```powershell
    New-NetFirewallRule -Name 'OpenSSH-Server' -DisplayName 'OpenSSH Server' -Enabled True -Direction Inbound -Protocol TCP -Action Allow -LocalPort 22
    ```

    **4. Check OrcaFlex installation:**
    ```powershell
    where.exe OrcaWave.exe
    ```
    If not found, install OrcaFlex from Orcina installer (required for DLL).

    **5. Check Python version:**
    ```powershell
    python --version
    ```
    Must be 3.9-3.14 for OrcFxAPI 11.6.2 compatibility. If not available: `uv python install 3.12`

    **6. Check uv:**
    ```powershell
    uv --version
    ```

    **7. Check Claude Code CLI:**
    ```powershell
    claude --version
    ```
    If not found: `npm install -g @anthropic-ai/claude-code` then `claude auth login`

    **8. Set up SSH key auth from dev-primary:**
    On dev-primary:
    ```bash
    ssh-copy-id <username>@192.168.0.184
    ssh <username>@192.168.0.184 "echo SSH_OK"
    ```
    Note: On Windows, if `ssh-copy-id` fails (admin users on Windows OpenSSH), manually append the public key to `C:\ProgramData\ssh\administrators_authorized_keys`.

    **Report back all outputs.** Key information needed:
    - OrcaWave.exe path (or "not found")
    - Python version
    - uv version
    - Claude Code version (or "not found")
    - SSH test result from dev-primary
  </action>

    **Step 1 — Create `scripts/remote/verify-licensed-win-1.sh`:**
    Diagnostic script that verifies all prerequisites from dev-primary via SSH. Must use environment variables for host/repo, not hardcoded absolute paths.

    ```bash
    #!/usr/bin/env bash
    # ABOUTME: Verify all Phase 7 prerequisites on licensed-win-1 via SSH
    set -euo pipefail

    REMOTE_HOST="${SOLVER_HOST:-<username>@192.168.0.184}"
    REMOTE_REPO="${SOLVER_REPO:-D:/workspace-hub/digitalmodel}"

    echo "=== Phase 7 Verification: licensed-win-1 ==="
    echo "Host: $REMOTE_HOST"
    echo "Repo: $REMOTE_REPO"
    echo ""

    # 1. SSH connectivity
    echo "--- SSH Connectivity ---"
    ssh "$REMOTE_HOST" "echo SSH_OK" || { echo "FAIL: SSH connection"; exit 1; }

    # 2. Python version
    echo "--- Python Version ---"
    ssh "$REMOTE_HOST" "python --version" || { echo "FAIL: Python not found"; exit 1; }

    # 3. uv
    echo "--- uv Version ---"
    ssh "$REMOTE_HOST" "uv --version" || { echo "FAIL: uv not found"; exit 1; }

    # 4. Claude Code CLI
    echo "--- Claude Code CLI ---"
    ssh "$REMOTE_HOST" "claude --version" || { echo "FAIL: Claude Code not found"; exit 1; }

    # 5. OrcFxAPI import chain (3-step: import, DLL, constructor)
    echo "--- OrcFxAPI Verification ---"
    ssh "$REMOTE_HOST" "cd $REMOTE_REPO && uv run python -c \"
import OrcFxAPI
print(f'OK: import succeeded')
version = OrcFxAPI.DLLVersion()
print(f'OK: DLL version = {version}')
d = OrcFxAPI.Diffraction()
print(f'OK: Diffraction() constructor, state={d.state}')
print('PASS: OrcFxAPI fully functional')
\"" || { echo "FAIL: OrcFxAPI verification"; exit 1; }

    # 6. Git status
    echo "--- Git Status ---"
    ssh "$REMOTE_HOST" "cd $REMOTE_REPO && git status --short" || { echo "WARN: Git check failed"; }

    echo ""
    echo "=== All checks PASSED ==="
    ```

    Replace `<username>` with the actual username reported in Task 1. Use environment variables (`SOLVER_HOST`, `SOLVER_REPO`) with the reported values as defaults so the scripts are configurable.
