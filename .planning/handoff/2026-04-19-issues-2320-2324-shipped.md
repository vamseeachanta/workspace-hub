### 2. `git mv` doesn't apply to plugin-installed skills

Repo skills live at `.claude/skills/<family>/...` (git-tracked). Plugin families (`gsd:`, `sparc:`, `workflows:`, `agents:`, plus others from `claude-plugins-official`) live at `~/.claude/plugins/cache/claude-plugins-official/<plugin-id>/<version>/...` — **not in the repo tree**. Any plan prescribing `git mv` on those is dead on arrival. See memory `feedback_plugin_cache_not_repo_tracked.md`.

### 3. `GIT_PRE_PUSH_SKIP=1` is sanctioned

Pre-push hook currently fails with `ModuleNotFoundError: yaml` for any push (all three worktree pushes this session hit it). Bypass via `GIT_PRE_PUSH_SKIP=1` is documented + logged per `.claude/skills/workspace-hub/worktree-pre-push-bypass-for-tier1-checks/SKILL.md`. Use until #2341 (or the earlier #2203) lands a fix.

### 4. Retry-loops with `git reset` are hazardous under auto-sync contention

If you run a retry loop that does `git reset HEAD -- . && git add X && git commit` while auto-sync is also touching the index, the reset may strip your staged edits before the add re-applies them (depending on which file-mtimes linter touched most recently). Result: commit lands with your message but wrong content. Cleaner pattern: re-verify staged diff against expected diff before committing, or use a dedicated worktree for docs-only edits too. Saved to memory.
