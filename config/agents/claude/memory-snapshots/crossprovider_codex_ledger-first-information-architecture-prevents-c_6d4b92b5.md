Machine-readable authoritative ledgers (registry.yaml, standards-ledger.yaml) are the source of truth; convenience summaries (markdown reports) are derived views only. When summaries diverge from ledgers, agents/users prioritize wrong work. Treat ledgers as canonical; regenerate summaries from ledgers, never the reverse.
