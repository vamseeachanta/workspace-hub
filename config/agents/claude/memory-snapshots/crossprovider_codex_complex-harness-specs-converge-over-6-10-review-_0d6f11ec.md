Plan reviews for multi-step systems (audit harnesses, policy gates, readiness checks) rarely converge in 1-2 rounds. Each round surfaces 2-4 major gaps: exit code contract, error isolation, precedence rules, edge case handling. Budget 6-10 iteration cycles, integrating feedback explicitly at each stage.
