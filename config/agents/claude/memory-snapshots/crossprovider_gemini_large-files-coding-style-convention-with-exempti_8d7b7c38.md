Enforce 400-line hard limit, 200-line soft target. Exemption categories: legacy (frozen, high refactor risk), data (taxonomies, constants), reference (engineering standard implementations), generated, ops (single-purpose scripts). Maintain .large-files-exclusions.yaml with justifications.
