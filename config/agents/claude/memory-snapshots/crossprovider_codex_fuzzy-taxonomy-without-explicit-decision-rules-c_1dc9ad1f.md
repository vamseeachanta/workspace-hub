Classifications like 'near-duplicate-same-intent' vs 'adjacent-specialization' fail when operationalized as heuristics. Weekly audit reports become noisy; operators stop trusting them within weeks. Define scoring rubrics with concrete examples and decision thresholds before automating. Use explicit matrices, not subjective judgment.
