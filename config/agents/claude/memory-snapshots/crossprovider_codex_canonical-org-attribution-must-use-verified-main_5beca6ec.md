Local project READMEs sometimes carry altered/incorrect org names (e.g., 'National Laboratory of the Rockies' in OpenFAST/WEC-Sim local copies). Wiki pages must record canonical maintaining orgs from official sources (NREL, Sandia/NTESS) and note the local anomaly only as a provenance caveat, not propagate the altered string.
