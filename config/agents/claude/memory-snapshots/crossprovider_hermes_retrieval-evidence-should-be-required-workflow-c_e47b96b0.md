GitHub issue workflows should enforce a minimum retrieval bundle as mandatory evidence: (1) issue truth (body, labels, criteria), (2) repo truth (existing code search, prior plans), (3) registry truth (ledger, registries, document metadata). Not optional; required before execution/review.
