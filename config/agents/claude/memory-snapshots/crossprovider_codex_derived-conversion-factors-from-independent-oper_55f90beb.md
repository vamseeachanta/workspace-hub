A derived factor (bbl_per_tonne) computed from independent primary sources (e.g., operator securities filing net rates + regulator official workbook tonnes) can be conversion-eligible if both sources are verifiable, the computation is documented, and policy explicitly permits derived factors. Broadens acceptable streams beyond direct assays.
