API standards dedicate ~25% of front matter to standardized boilerplate: "SPECIAL NOTES" (liability & review cycles), copyright/licensing footer, foreword, table of contents. Structural pattern is identical across all API documents (614, 617, 620, etc.); scanning for boilerplate is efficient but yields low signal.
