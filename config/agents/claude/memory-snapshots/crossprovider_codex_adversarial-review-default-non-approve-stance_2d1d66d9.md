Code and plan reviews operate with default assumption of defect; APPROVE is the exception, not the rule. Every finding must cite exact file path, line number, or quoted claim—statements without citations are not findings. Empty findings list is a review failure; if no concrete defects found, explicitly state which checks passed. Prefer MINOR/MAJOR over unnecessary APPROVE.
