Narrow plans must explicitly exclude related but out-of-scope work by name (e.g., 'Hermes out of scope', '#2435 gated separately', 'upstream audit deferred to #2441'). Vague language like 'related work' creates scope creep. Out-of-scope decisions should appear in the plan as named rejections.
