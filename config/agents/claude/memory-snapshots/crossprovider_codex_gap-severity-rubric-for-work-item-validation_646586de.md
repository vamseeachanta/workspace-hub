Use a three-tier gap classification for unresolved issues: P1 (blocker: required artifact, source, legal, or core-context blocker) → pause and revise; P2 (quality weakener: materially impacts planning repeatability) → flag but may continue; P3 (enhancement only) → proceed. No unresolved P1 allows continuation.
