Codex can hang on 'Reading additional input from stdin...' despite active process, Gemini fails with 429 capacity errors, sandbox startup fails with bwrap permission errors. These are recoverable; inspect logs before assuming crash. Do not count zero-byte logs as process death while the process is live.
