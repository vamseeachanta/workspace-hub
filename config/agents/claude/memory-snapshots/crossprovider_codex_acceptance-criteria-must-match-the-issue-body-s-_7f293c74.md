Narrowing the acceptance criteria to a subset of the stated issue deliverable leaves the issue closeable without fully addressing it. For example, if issue #2459 says 'restore workflow to meaningfully green state', don't accept 'matrix advances past current first blockers' if later stages are still red—that's scope creep in reverse.
