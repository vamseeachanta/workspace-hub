In async multi-agent work, handovers should prioritize non-obvious project gotchas, environment quirks, and configuration traps over code summaries. Agents can read code; handovers must transfer domain-specific knowledge they can't rediscover (e.g., data(cost): breaks CI, NTFS-FUSE mount stalls git, not_public row is a deliverable not a failure).
