Issue/plan/skill/report duplication spans multiple locations (plans, reports, handoffs, skills, GitHub issues) across sibling repos. Searching one canonical location (e.g., `docs/plans/`) alone misses duplicates; effective deduplication requires searches across all artifact types before creating new issues.
