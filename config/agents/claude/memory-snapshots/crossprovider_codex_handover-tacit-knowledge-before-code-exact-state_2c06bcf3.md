Handovers to future agents prioritize hard-won gotchas (mount stalls git, CI naming traps, data constraints) before restating code. Pin exact counts, SHAs, and branch names to prevent chasing false discrepancies. Silently describing an unmerged branch as 'current' or omitting pre-merge state sends the next agent down the wrong path.
