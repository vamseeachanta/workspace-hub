Plan review verdicts default to MAJOR/MINOR unless every correctness-critical claim is affirmatively verified AND no gaps are found. Empty reviews (silence/no findings) are failures, not implicit approves. When in doubt, return MINOR or MAJOR; APPROVE is the exception.
