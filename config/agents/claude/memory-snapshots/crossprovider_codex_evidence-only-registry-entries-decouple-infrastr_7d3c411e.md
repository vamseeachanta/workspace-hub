When source coverage is incomplete, evidence (e.g., AAPG API ranges, discovery-test data) can be stored as 'evidence-only' separate from accepted conversion factors, allowing infrastructure implementation to ship while leaving the issue open for coverage gaps. This decouples delivery from perfect data availability.
