When a plan was revised after a prior review round, old r1 review artifacts remained but the new plan's verification section only partially re-verified them through updated selector/sidecar paths. Generic scans over retained artifacts are insufficient if the new logic changes how they should be validated. Follow-on plans must explicitly verify each retained historical artifact through updated acceptance criteria.
