Filling attribution gaps with domain knowledge (e.g., inferring 'FPSO implies quantity=1' or 'SURF EPCI implies flowlines/risers without stating counts') is INFERENCE, not CLEAN. This distinction is critical when claiming data grain; 2 of 10 sample awards were CLEAN, 5 INFERENCE, 3 FAIL. Do not soften inference gaps with manufacturing plausible attribution.
