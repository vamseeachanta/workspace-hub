Criteria phrased as 'distinct or explicitly documented' permit implementations that technically pass while reducing engineering fidelity (e.g., reusing baseline geometry across distinct specs). Acceptance criteria should specify concrete metadata/provenance requirements and close loopholes with test oracles that verify both presence and semantic correctness, not just literal compliance.
