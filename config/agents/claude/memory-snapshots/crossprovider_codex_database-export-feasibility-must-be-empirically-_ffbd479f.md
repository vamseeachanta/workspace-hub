Plans proposing comprehensive ABS database export assume all databases are exportable (CSV/PDF/HTML) without live verification. ABS Databases page describes most resources as dynamic search portals; only 'Newly Classed Vessels' is explicitly described as downloadable Excel. ABS Record is a live database with continuous status updates. Future plans must include per-database feasibility probes (export format, pagination, login/session requirements, rate limits, snapshot semantics) before approval.
