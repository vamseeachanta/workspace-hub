Source data stating value ranges (e.g., 20–39 °API for Ayoluengo) must remain evidence-only. Only production-weighted, operator-stated, field-average, or regulator-published factors can drive conversion. Midpoint proxies are derived, not source-stated, and should never bypass the evidence-only classification.
