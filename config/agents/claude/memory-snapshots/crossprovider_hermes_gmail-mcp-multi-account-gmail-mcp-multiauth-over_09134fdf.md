gmail-mcp-multiauth (npm fork, 381K downloads/mo base) better than himalaya for 3-account OAuth setup—each account becomes a named MCP server with per-account OAuth2 tokens. Himalaya supports multiple accounts but less elegantly for MCP. Critical gap: no existing MCP has unsubscribe capability; must parse List-Unsubscribe headers manually.
