Large reference standards like API RP 579 decompose into sections and appendices with distinct scopes (Section 3: Brittle Fracture Assessment; Appendix A: Thickness/MAWP Equations; Appendix B: Stress Analysis Methods). Index each component separately rather than treating the standard as an atomic unit.
