Reusing the same symbol (e.g., F_prop) to mean both raw propeller thrust and post-deduction effective hull force across different sources creates silent ambiguity in synthesis. Canonical parameter definitions must be maintained and applied consistently; ambiguous cases must be renamed or explicitly clarified.
