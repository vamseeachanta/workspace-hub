Plans may mention restricted-access standards (JEDEC, IPC, DNV, API) only as taxonomy targets or gaps, unless backed by local accessible source text in `data/design-codes/` or `data/document-index/`. Overclaiming compliance ('JEDEC-compliant', 'extracted from IPC') without source text triggers MAJOR blocker per #2508 adversarial review.
