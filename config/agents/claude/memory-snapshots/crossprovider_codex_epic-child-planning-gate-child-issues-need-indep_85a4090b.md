When using an existing GitHub issue as an epic (label `tracker`), each child issue must have its own plan artifact, adversarial plan review, and explicit user approval before any implementation. No child is dispatch-ready from creation. This prevents unplanned scope and ensures reviewability at both plan and code stages.
