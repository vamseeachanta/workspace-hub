Plans listing files in 'Files to Change' or 'Acceptance Criteria' should reference verified existence. Use attestation evidence to confirm; plans claiming artifacts will be created should explicitly mark them as new. #2311-2312 listed removed scripts as if still present without clarity on new vs. cleanup targets.
