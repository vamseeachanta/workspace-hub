GTM/contractor research distinguishes between: (1) accessible official fleet/project page → cite with URL + date, (2) blocked/missing/redirected → explicitly state 'no public proof at <url> [date]'. Probing URLs via curl/BeautifulSoup can timeout or truncate output; avoid claiming evidence without accessible proof. Unsourced rows create blocker findings in reviews.
