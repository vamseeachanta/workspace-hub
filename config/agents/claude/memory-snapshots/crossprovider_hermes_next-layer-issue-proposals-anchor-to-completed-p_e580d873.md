When proposing 3-5 child issues after a feature layer ships (e.g., #2173/#2174), verify live GitHub issue state (not snapshots), search for overlapping open issues, and anchor each proposal to what the prior layer accomplished. This prevents duplicate effort and ensures coherent sequencing.
