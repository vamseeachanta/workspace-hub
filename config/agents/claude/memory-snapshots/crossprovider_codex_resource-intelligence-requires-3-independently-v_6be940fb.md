Embedded grep snippets, prose assertions, and inline examples do not count as independent verification. True resource intelligence requires concrete findings from separate evidence artifacts: file existence with paths, prior checked-in review reports with commit refs, live issue status snapshots with `gh` tool output timestamped, and direct quotes from standards documents with section numbers and line references.
