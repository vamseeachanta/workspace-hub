Generic searches (e.g., 'API', 'condensate') pollute results. Effective terms: field-specific + stream type + property + regional/language variants + document type (e.g., 'Gaviota condensate assay', 'Viura API gravity', 'Albatros bbl.tm'). Spanish/English bilingual and date-restricted searches improve retrieval.
