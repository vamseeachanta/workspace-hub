A handover's highest-value payload is hard-won gotchas and non-obvious constraints that agents cannot rediscover alone (e.g., data(cost) breaks CI, NTFS-FUSE mounts stall git, 'not_public' rows are deliverables not failures). Pin counts to post-merge state and explicitly flag what is not yet merged so the next agent doesn't chase a discrepancy.
