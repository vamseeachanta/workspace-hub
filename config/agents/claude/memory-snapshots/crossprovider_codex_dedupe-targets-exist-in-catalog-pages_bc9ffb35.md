Before creating a new standards resolver page (e.g., iso-2063.md), grep both standards/ and sources/ for dedupe hits. Existing coverage often lives in catalog sources (e.g., og-standards-iso.md listing many ISO codes with revision/file count metadata) rather than individual pages. Augment catalogs; do not create duplicates.
