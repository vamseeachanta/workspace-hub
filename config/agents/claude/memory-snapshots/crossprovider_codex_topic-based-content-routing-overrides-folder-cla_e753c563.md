Route documents by actual subject matter (geotechnical, marine, production, drilling) not storage folder. An API standard about offshore platforms routes to marine-engineering, not engineering-standards; geotechnical content routes to geotechnical-engineering. Content-first routing prevents miscategorization and enables cross-domain deduplication.
