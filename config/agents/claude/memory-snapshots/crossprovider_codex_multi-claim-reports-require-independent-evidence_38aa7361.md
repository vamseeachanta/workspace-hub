Reports with multiple numerical claims, plots, tables, and conclusions need each claim bound to distinct evidence edges, not one claim per report. Tests checking 'identical inputs = identical outputs' don't prove no mutation; compare all files to a frozen baseline to detect modifications to immutable artifacts.
