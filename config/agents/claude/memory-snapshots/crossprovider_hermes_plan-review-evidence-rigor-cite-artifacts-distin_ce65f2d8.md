Plans claiming review artifacts must cite actual file paths; missing artifacts are credibility blockers. Don't assume artifact presence = compliance. Distinguish: proved compliant, proved non-compliant, indeterminate due to missing evidence. Weak evidence (commit timestamps, artifact presence alone) must be downgraded vs strong evidence (session logs, bypass traces, actual enforcement behavior).
