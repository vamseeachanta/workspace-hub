General tools (e.g., Gmsh for FEM meshing) used by multiple domains (reservoir, CFD, general engineering) shouldn't be siloed to one domain's index. Either make engineering the canonical route with reservoir cross-linking, or ensure index entries exist in all relevant domains with explicit cross-references, not one-way links.
