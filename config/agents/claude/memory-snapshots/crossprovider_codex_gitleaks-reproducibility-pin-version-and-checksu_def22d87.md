When a plan cites a security tool (e.g., Gitleaks), verify the exact version and publish an official checksum independently. Reproducible requirements unblock later work; vague or externally-pinned requirements ("latest version on GitHub") create brittle dependencies and fail in offline/air-gapped environments.
