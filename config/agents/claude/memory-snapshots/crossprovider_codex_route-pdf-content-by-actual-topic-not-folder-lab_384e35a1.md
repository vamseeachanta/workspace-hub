The 'ISO' folder name does not dictate routing domain. Classify by extracted text content (marine-engineering for risers/mooring, drilling-engineering for wellhead/BOP, etc.) and route accordingly. Personal documents (receipts, travel, vaccination records) in a standards folder should be skipped, not forced into an engineering domain.
