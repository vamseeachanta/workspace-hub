Plans must avoid deferring correctness-critical decisions to execution time. Deliverables, files-to-change, tests, and acceptance criteria must align. Tests must be concrete enough to enforce policy (not just render it as documentation). Budget/policy compliance fields must be machine-checkable and schema-complete. Stale review-process language should be removed from final plan body before approval.
