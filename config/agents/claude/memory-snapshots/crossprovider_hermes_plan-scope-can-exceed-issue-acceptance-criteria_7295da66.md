Planned changes often specify broader scope than the issue actually requires. Review planned file changes and acceptance criteria against the issue body; scope mismatch creates implementation risk and scope creep. If plan narrows scope to avoid a blocker, verify that narrow scope still satisfies the issue's acceptance rule.
