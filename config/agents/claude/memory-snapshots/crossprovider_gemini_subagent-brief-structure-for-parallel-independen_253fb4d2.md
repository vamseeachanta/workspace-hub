Structured briefs for parallel subagent dispatch include: objective, scope command(s), deliverables list, explicit constraints (e.g., 'use uv run only', 'no network access', 'no refactoring unrelated modules'), and no-go areas. Prevents scope creep and clarifies success criteria for independent agents.
