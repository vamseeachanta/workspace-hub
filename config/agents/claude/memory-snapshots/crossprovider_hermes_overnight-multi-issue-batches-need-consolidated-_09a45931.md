When closing multiple issues in a session (e.g., #2324, #2320, #2322), create one consolidated handoff documenting final status of all issues, pushed branches, preserved worktrees, dirty-main warnings, and prioritized next-session recommendations. Prevents loss of context across handoff boundaries.
