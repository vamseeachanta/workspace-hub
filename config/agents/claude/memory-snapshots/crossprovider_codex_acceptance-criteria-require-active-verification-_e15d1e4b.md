When a spec lists acceptance criteria (e.g., 'all URLs reachable via HEAD/GET fallback', 'volatility classes consistent'), those must be affirmatively verified and evidence recorded or reported, not assumed. Spot-check or exhaustive verification with proof before sign-off.
