Move enforcement from warn to gate mode only when strict preconditions are met (5 consecutive CI passes, prior wave completion, convergence criteria). Wave-based migration (starting with smallest repos) and rollback triggers mitigate risk of mass-move breakage. Schema compliance gate on active WRK items catches inconsistency early.
