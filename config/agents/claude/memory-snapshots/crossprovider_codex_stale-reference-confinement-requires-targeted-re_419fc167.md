When cleaning up references to deleted scripts (e.g., stage-transition cluster, lifecycle-script cluster), distinguish allowed surfaces (legacy maps, historical reports) from forbidden surfaces (live instructional docs) via targeted regression tests scoped to each cluster, not broad stale-reference sweeps. Confinement is distinct from deletion.
