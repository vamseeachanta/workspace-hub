Python semiconductor scripts follow directory structure: `scripts/semiconductor/` for implementations, `tests/semiconductor/` for tests, `data/semiconductor/` for artifacts, `docs/reports/` for portfolio reports. Use this pattern for new semiconductor automation work (e.g., GDSFactory/KLayout).
