When reviewing plans for validators/enforcement: hunt for schema reconciliation gaps (existing enums colliding), legal evidence validation (stale, fake, wrong mode), allowlist-only projections, self-artifact compatibility tests, stale-pointer detection, and explicit manual vs. CI boundary definition. Non-approval is the default unless all are addressed.
