Plans deferring generated outputs to external tools (licensed software, CAD, OrcaFlex) must capture durable fingerprints in committed reports. Recording only metadata paths or test-pass status is insufficient for reproduction/audit; commit manifest files with hashes of generated artifacts, input specs, and generation commands so outputs are verifiable and reproducible.
