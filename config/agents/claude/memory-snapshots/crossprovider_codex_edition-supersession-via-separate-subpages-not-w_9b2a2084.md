When multiple editions of a standard exist (e.g., API 579 Appendix D from Jan 2000 vs June 2001), create separate wiki subpages and annotate which edition was authoritative for specific content (e.g., '2001 used for table extraction'). This preserves historical coverage while signaling the preferred version for each section.
