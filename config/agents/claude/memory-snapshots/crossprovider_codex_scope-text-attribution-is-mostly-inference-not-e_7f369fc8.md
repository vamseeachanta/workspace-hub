Free-form descriptions in records (contracts, project scope statements, awards) cannot reliably yield structured asset data (quantities, types, work packages) without domain knowledge or inference. Records that look rich in text are actually sparse for structured extraction. Extraction from unstructured narrative requires explicit inference classification.
