Classify planning gaps by severity: P1 (blocker—legal/core-context required), P2 (weakens quality/repeatability), P3 (enhancement). Automate gate decisions: unresolved P1s trigger pause-and-revise; zero P1s allow continue-to-planning. This makes gap severity actionable and prevents under-specified planning.
