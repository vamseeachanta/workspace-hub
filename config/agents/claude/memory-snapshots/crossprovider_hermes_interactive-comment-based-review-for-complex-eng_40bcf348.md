For force/moment calculation revisions, GitHub comments serve as an engineering decision ledger. Each component (surge X, sway Y, roll K, etc.) requires capture of: model/source, sign convention, application point, moment arm/reference, units/rounding, chart/table requirements, and report wording—all pulled into a canonical plan only after interactive decisions stabilize.
