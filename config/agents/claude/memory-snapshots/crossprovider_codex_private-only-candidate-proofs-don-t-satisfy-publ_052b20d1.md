Artifacts stored only in `/mnt/ace` or other private paths cannot be reviewed in Git and do not satisfy plan acceptance criteria that require proof. Create a sanitized, repo-resident summary of the candidate universe (URLs, page counts, filters) that is reviewable in plan-review.
