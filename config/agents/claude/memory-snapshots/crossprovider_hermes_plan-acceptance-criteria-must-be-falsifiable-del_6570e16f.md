MAJOR findings repeat across #2726–#2729: acceptance criteria using open-ended process language ("will review", "pending approval") or deferring to backlog docs instead of exact testable outcomes. Criteria must name concrete artifacts, tests, or executable gates. Vague criteria hide scope creep.
