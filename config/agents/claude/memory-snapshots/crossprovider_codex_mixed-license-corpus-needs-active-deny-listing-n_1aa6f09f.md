When a corpus contains proprietary/vendor PDFs alongside MIT/CC-BY content, the license-triage workflow must include an explicit deny-list of vendor patterns (Halliburton, Schlumberger, Baker Hughes, etc.) that blocks ingestion before human review. Relying on operator vigilance during content review is a blocker-level risk for public CC-BY-4.0 publications.
