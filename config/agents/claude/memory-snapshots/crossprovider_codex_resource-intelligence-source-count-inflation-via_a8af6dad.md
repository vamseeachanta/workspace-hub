Plans frequently claim 'Distinct sources: N' by counting standards, documents, and wiki pages broadly without concrete findings attached to each source. This inflates counts and fails the mandatory '≥3 distinct sources with concrete findings' requirement. Require each source to carry a quoted finding or evidence excerpt.
