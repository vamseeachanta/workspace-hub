Each autonomous Codex bundle work unit needs stable identity: bundle name (e.g., `assetutilities-bundle`), associated GitHub issues (e.g., `#72,#75`), and git branch name (e.g., `codex/burn-20260511-assetutilities-bundle`). Track issue state (OPEN vs CLOSED), branch remote SHA, and worktree cleanliness as part of inventory. Enables post-mortems and restart logic.
