When auditing workflow compliance, define an explicit matrix: each cohort (engineering-critical, non-engineering, legacy, mixed/ambiguous) with its inclusion rule and compliance rule. Prevents issues from being accidentally excluded or misclassified, and clarifies what 'compliance' means per category.
