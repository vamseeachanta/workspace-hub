An archived page from a company's own domain (e.g., LGO operator page via Wayback) is defensible direct evidence, not a scrape. However, Wayback captures can be incomplete (JavaScript-rendered content missing, subpages unreachable); always verify the specific fact/number exists in the captured content text, not just in page title/URL. Example: LGO Ayoluengo archived page directly contains "37 degree API" and operator context, supporting the 37° API conversion factor.
