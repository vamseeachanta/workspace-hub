Path-based filtering alone is insufficient for public artifact safety. Even in approved public wiki directories (e.g., wikis/engineering/), private metadata files (CLAUDE.md, SOURCE_INVENTORY.md, _audit/) must be explicitly removed. Requires semantic understanding of file purpose, not just directory patterns.
