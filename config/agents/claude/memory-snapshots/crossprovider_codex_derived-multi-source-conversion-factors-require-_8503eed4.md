When no direct assay exists, a derived factor from independent operator (e.g., net barrels/day from 10-K) + regulator (e.g., tonnes from CORES) sources can be valid but requires explicit policy allowance and full derivation documentation. Registry schemas may lack `derivation_basis` or `derived_from_sources` fields, leaving multi-source factors under-documented. Example: Gaviota 1992–93 condensate (Murphy 10-K barrels + CORES tonnes → 8.29 bbl/t) is policy-eligible only if documented and approved explicitly.
