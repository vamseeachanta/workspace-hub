When handing work to another agent, document the discovered traps and non-obvious constraints first—these are higher-value than the code itself. Pin all metrics/counts to a known git state (post-merge or pre-merge) to prevent chasing discrepancies. Make ownership and authorization gates explicit (e.g., owner-gated merge, no self-merge, no external send).
