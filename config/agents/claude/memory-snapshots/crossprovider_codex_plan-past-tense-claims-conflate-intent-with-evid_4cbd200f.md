Plans written as 'the gate will be added at X' without citing merged PRs create a completion-illusion risk. Prior plan #565 listed 20 tests as though already done, shipped with 8 implemented, and passed review because past-tense language read as fact. Always verify claimed implementation against actual repo content, not plan prose.
