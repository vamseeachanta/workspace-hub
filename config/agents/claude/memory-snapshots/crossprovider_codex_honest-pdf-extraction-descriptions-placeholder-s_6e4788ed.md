Figures that are caption-only (imagery not text-extractable) should be labeled 'caption-only; figure imagery not text-extractable — defer to vision pass' rather than stub placeholders like 'inspect source PDF'. Honesty about extraction limits is more useful for downstream consumers and reviewers.
