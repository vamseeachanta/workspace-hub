Outreach should follow technical and commercial preparation, not serve as discovery. Build separate internal prep (candid assumptions, risks, unknowns) and client-facing docs (verified facts, demonstrated understanding, low-risk diagnostics). Transparency should flow throughout engagement via shared evidence, agreed metrics, and decision registers—not appear as final reporting. Phased trust-and-transfer models work better than black-box recommendations.
