API 579 Appendix E provides residual stress distributions required for crack-driving-force and plasticity-interaction factor calculations. As-welded vs. PWHT conditions produce significantly different distributions; local or uncontrolled PWHT elevates stresses beyond controlled PWHT, forcing conservative assumptions when PWHT type is unknown.
