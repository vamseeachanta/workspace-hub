Assertions like 'independently authored' and 'demonstrably not reverse-derived' are not testable without supporting evidence. Require: clean-room role/access audit, public input citations, generation-rationale document, authorship declaration, and similarity-disclosure review. Fixtures can verify labels but not author intent; access separation is load-bearing.
