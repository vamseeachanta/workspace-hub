When a method/page/standard is published with backing code, adversarial review should hunt specifically for claims (accuracy figures, algorithm behavior, output confidence, diagnostic reliability) the code cannot actually support. A page being 'mostly correct' is not a verdict—each potential overclaim needs explicit assessment against code reality.
