Single-purpose deliverables (e.g., a retrieval-augmented planner) that expand to touch CLI, conformance packages, workflow templates, skills, and hook installers signal scope creep. Either provide explicit justification for the bundling or separate the work into focused child issues. Do not hide unrelated changes under a narrow deliverable claim.
