Define explicit policy on allowed metadata (counts/types/taxonomy yes; raw paths/names/bodies/OCR no), output consumers, and permitted analysis before broad indexing. All client-data roots should default to needs-human-review until schema approval. Avoid post-hoc content scrubbing.
