For infrastructure/architectural planning issues: (1) draft the plan structure and acceptance criteria without source inventory, (2) domain owner curates/adds source references and authoritative links, (3) adversarial review after sources are locked in. This avoids multiple review cycles when sources change. Pairs with `status:plan-review` label only after phase 2 is complete.
