When multiple fix paths exist (e.g., skip vs. repoint, bypass vs. fix), the approval-safe default is the most conservative option (skip/bypass) until owner-directed discovery explicitly unblocks the broader path. This avoids silent regressions when intermediate discovery is incomplete.
