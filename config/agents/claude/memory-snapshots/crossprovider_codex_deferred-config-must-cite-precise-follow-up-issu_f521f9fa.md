Deferring Node version pinning, Vercel runtime, engine constraints, etc. to Known Debt is acceptable only if the plan cites the exact follow-up issue number (e.g., 'G | No engines field; see #2999'). 'Known debt' without an issue number is untracked cleanup risk and may be lost.
