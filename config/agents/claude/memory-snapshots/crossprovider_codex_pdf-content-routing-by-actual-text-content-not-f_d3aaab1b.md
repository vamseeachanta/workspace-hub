Misfiled documents are common (e.g., 'ISO' folder contains BVI admin docs, pet import certificates, business cards). Extract text with `pdftotext`, check fonts with `pdffonts`, and examine metadata to determine true domain and routing. Folder names are unreliable; classify by content only.
