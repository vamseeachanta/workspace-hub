Scratch artifacts (e.g., `/tmp/issue-*.md` from `gh comment --body-file`) are EXPECTED and don't block forward progress; unrelated modified/untracked files are UNEXPECTED. Explicit classification in audit report is required before claiming 'clean dispatch status'.
