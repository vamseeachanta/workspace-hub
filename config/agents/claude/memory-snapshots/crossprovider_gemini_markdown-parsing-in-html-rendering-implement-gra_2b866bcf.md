Parsing markdown structures (e.g., ac-test-matrix.md) into HTML tables is fragile when generated by AI agents; format divergence causes silent failures or malformed output. Always implement graceful fallbacks (render raw markdown content) on format mismatch. Parameterize reusable rendering functions to handle different file naming conventions rather than hardcoding.
