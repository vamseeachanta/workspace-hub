When a plan claims a constraint will be enforced (e.g., 'hostile examples assembled from fragments, not committed verbatim'), verify that the actual validator/tooling implements it. Finding hostile test fixtures stored verbatim is a blocker even if the plan prose says otherwise, because the tooling doesn't enforce the claim.
