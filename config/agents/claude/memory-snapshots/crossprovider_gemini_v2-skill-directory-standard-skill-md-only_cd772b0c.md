Skill directories follow v2 guidelines using SKILL.md exclusively; README.md is an anti-pattern. Nearly all 500+ skills in the ecosystem follow this convention. Skill audit tools should not flag missing README.md as violations; instead, flag its *presence* as a violation per v2 standards.
