Plans claiming 'added X', 'wired Y', or 'gate is in place' before implementation confuse reviewers about what is already done vs. what is proposed. Use future tense ('will add', 'plan to wire') consistently. Flag any present-tense state-claim in a resource section as unverified unless the artifact is embedded in the plan.
