Plans frequently cite review artifacts as acceptance criteria (e.g., '-r3.md files'), and the files exist, but are interim single-author reviews rather than fresh external reruns. The gate appears satisfied but isn't — acceptance criteria must explicitly require new artifact names or timestamps when a fresh rerun is stated as mandatory.
