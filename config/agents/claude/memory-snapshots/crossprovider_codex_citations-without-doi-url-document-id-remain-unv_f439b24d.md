Plans citing papers, broker listings, or external sources by number or name alone (e.g., 'OTC-24523', 'class-society DB') without DOI, GitHub link, or URL leave verifiability gaps. Every source claim must include at minimum (author, year, title) or a resolvable link; bare paper numbers fail the citation-verifiability check.
