Tier-1 repos can host multiple domain-specific kanban boards (e.g., orchestration, operations, engineering, data-pipeline, standards) in addition to repo-level board. Each domain lanes include Planning Needed, Ready (plan-approved), In Progress, Cross-Review, and Decisions/User Input. Provider and machine execution owners must be assigned per issue.
