Tier compliance findings into Authoritative (direct proof like skill invocation), Secondary (artifact inspection), and Fallback (narrative evidence) levels. Absence of one tier doesn't fail the issue; mark it indeterminate for that dimension and evaluate other dimensions independently. Supports confidence-graded reporting.
