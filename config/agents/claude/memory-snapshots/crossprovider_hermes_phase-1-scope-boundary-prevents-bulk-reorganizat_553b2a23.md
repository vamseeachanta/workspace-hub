Approved repo-structure Phase 1 plans are bounded to contract/checker/tests/docs/enforcement wiring only; no bulk source/package reorg, broad docs migration, generated-artifact deletion, or runtime changes. Boundary is hard gate that prevents scope creep requiring follow-up sessions; explicit user approval is required to expand beyond Phase 1.
