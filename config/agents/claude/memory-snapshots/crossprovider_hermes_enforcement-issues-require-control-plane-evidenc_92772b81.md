Implementation/enforcement issues need proof at the control plane (actual hooks, tests, CI behavior, bypass traces) not documentation inventory. Docs-only plans for enforcement gaps don't prove the gap is closed—they just prove someone wrote about it. Real enforcement proof is behavioral.
