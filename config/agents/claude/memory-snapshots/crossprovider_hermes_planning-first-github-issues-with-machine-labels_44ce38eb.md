Workstation repo placement and tier-1 configuration changes must be codified as planning-first GitHub issues (e.g., #2754–#2758) with machine-scoped labels (machine:*, cat:*, domain:*) and status:needs-plan before any clone/move/delete/sync operations. This creates decision record and explicit approval gate.
