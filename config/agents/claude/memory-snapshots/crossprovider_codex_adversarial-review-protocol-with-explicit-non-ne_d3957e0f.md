Adversarial reviewer operates under six rules: opening framing assumes defects, no praise/restatement (anti-flatter), default non-approve, evidence required (citations mandatory), retrieve-then-verify (tool invocations assumed wrong until checked), and silence-is-failure (must state checks run if no findings found). Violations of the last rule (empty review without explicit checks listed) are immediate failures.
