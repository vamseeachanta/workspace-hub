When ingesting licensed standards (API, ASTM, SAE, etc.), routing decision is load-bearing: generic wiki accepts only own-words methodology/interpretation with publisher citations; licensed PDFs and project-derived content stay in client-private wikis. Multi-root deduplication requires a canonical source ledger per code_id to prevent blind re-ingestion of duplicates across source roots (e.g., mkt-a-codes vs O&G-Standards).
