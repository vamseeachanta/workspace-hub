Plans tagged `cat:harness` or `cat:operations` must follow the template shape including explicit Resource Intelligence Summary with subsections (Existing repo code, Documents consulted, Gaps identified, Evidence). Freeform RI summaries trigger reviewer MAJOR even when the core idea is sound. Template adherence prevents predictable blocking findings.
