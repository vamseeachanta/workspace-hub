Plans that pin specific ISBNs, DOIs, URLs, or version identifiers alongside artifact deliverables create an implicit contract that the delivered artifact must match those exact IDs. Mismatches are blocking defects (not style issues), because they break the ability for reviewers to independently verify the source or reproduce the work.
