The `data/inventory/` dataset covers 4,125 Excel workbooks: 3,730 riser, 238 jumper, 62 mooring domain calcs. It is not a subsea field-development project master database. SubseaIQ-related artifacts contain only 10 synthesized GoM fields, not thousands of project records. These are distinct inventory scopes; search separate sources for field-intelligence data.
