When defining 'all agents' for workflow adoption issues, enumerate the finite provider entry surfaces explicitly (e.g., Claude, Gemini, Codex, Hermes) and lock that set at approval time. Future providers added after approval do not retroactively change the issue's scope—they trigger follow-up onboarding work instead. This prevents scope creep and keeps closure auditable.
