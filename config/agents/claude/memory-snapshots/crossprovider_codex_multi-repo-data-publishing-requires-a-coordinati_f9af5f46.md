Publishing derived data (e.g., to Hugging Face) that spans multiple repos and involves licensed solvers requires an approved parent issue that coordinates across repos, owns the publication contract, and gates against conflicting parallel work. Naive parallel pushes risk schema misalignment and provenance gaps.
