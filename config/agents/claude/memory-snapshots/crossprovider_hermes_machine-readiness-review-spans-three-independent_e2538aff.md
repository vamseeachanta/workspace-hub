Multi-machine ecosystem health requires separate audits: (1) settings/config parity, (2) execution readiness (auth, tools, dispatch capability), and (3) intelligence freshness + accessibility (broken links, stale indexes, missing syncs, inaccessible paths). Treating these as one audit masks layer-specific failures.
