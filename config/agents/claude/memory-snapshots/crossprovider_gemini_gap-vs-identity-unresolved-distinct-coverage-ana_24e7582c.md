A `gap` is an indexed source with canonical key but no matching wiki page (actionable backlog). An `identity-unresolved` source cannot be safely matched (missing/ambiguous key, only md5, or bare hex). Only gaps count toward coverage completeness; unresolved records surface for manual remediation.
