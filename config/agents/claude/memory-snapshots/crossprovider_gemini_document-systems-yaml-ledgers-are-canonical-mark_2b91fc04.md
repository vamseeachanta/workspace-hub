In document-index and metadata systems, store authoritative state in YAML ledgers/registries and regenerate Markdown summaries as derived views. Never edit summaries directly; enforce single source of truth via validators. Observed drift: resource-intelligence-maturity.yaml reported 425 docs in scope but .md summary showed 5 docs.
