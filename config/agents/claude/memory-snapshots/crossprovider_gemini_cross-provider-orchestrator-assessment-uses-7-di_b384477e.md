When assessing multi-provider capability (e.g., Claude vs Codex vs Gemini), use a 7-dimensional scorecard: (1) lifecycle completeness, (2) gate compliance (first-pass vs remediation), (3) TDD faithfulness, (4) user-review integration, (5) skill invocation, (6) session log review, (7) spec divergence. Enables fair provider comparison and routing rule recommendations.
