User review decisions are captured in versioned evidence artifacts at standardized paths (`assets/WRK-<id>/evidence/user-review-plan-draft.yaml`) using templates (`specs/templates/user-review-plan-draft-template.yaml`). This makes decision trails auditable and enables review of user choices at later stages.
