Autonomous agents should explicitly halt and refuse re-launch when blockers are governance/scope decisions (e.g., 'remove legacy path vs preserve', 'wire royalty citation now vs later', 'include full-suite blockers') even if technical resources allow continuation. Distinguish 'can we run' (technical) from 'should we run' (governance). Document blocker evidence without attempting to bypass.
