Plans stating 'Round 1' / 'Reviewed by: Claude (r1)' while incorporating r2/r3 fixes create review chain confusion. Artifact maps, adversarial-review summaries, and status strings must be updated when new review rounds land. Stale metadata makes it hard for reviewers to know what version they are reading.
