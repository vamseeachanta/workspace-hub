Vague language like 'explicit boundary', 'documented alternative', 'no private fields', or 'same offshore workflow' creates validation gaps that external reviewers cannot verify. Enforcement gates must specify exact patterns: regex for compliance tests, frozen reference values/geometry, or measurable boundary conditions (e.g., 'quasi-static only', not 'standard workflow'). Prose-only acceptance criteria leave loop-holes between intent and implementation.
