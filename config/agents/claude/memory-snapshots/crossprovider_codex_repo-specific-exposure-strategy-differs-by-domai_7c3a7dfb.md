Each repository (e.g., digitalmodel, worldenergydata, workspace-hub) has different safe-to-expose targets—some allow full implementation links, others only public summaries, others are entirely clearance-gated. Maintain an explicit matrix of (domain/repo → safe targets → exposure form) rather than ad-hoc approvals.
