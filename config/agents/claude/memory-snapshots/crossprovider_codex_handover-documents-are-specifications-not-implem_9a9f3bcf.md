A technical handover (e.g., CFD tank sloshing spec) that lacks a reviewed plan, approval marker, and canonical GitHub issue status cannot trigger implementation. status:ready-for-scope means readiness assessment only. Always verify approval gates (canonical plan, review artifacts, owner sign-off) before starting work, even when handed a complete technical specification.
