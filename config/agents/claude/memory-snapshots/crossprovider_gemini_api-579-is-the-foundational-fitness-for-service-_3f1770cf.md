API RP 579 defines standardized procedures for FFS assessments of pressurized equipment in refining/petrochemical industries, integrating stress analysis, material properties, and NDE requirements. It is cross-referenced by equipment-specific inspection codes (API 510, 570, 653) and covers brittle fracture, metal loss, blisters/laminations, and crack assessment.
