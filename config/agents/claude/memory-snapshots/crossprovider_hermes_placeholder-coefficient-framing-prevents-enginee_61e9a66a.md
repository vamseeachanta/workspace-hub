When using transparent scaling functions (e.g., `Cx=1.05*abs(cos ψ)`) for first-cut comparison, explicitly downgrade framing from 'OCIMF-style' to 'OCIMF-inspired placeholder' or 'transparent first-cut scaling'. Engineers read 'OCIMF-style' as calibrated/vessel-specific; placeholder coefficients dominate totals and can mislead if presented as pedigree. Reword everywhere framing appears.
