When a parent issue previews content (e.g., data categories, principles, transfer intent) and a child issue owns operational procedures (e.g., authority matrix, transfer checklist), scope creep results. Explicit boundaries prevent duplication: parent previews categories/principles only; child owns complete operational request, authority matrices, and procedures. State handoff explicitly in issue description.
