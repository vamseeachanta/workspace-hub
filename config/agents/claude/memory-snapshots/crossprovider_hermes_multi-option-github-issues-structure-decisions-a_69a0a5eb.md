For decisions with multiple choice options (e.g., which tier-1 repos per machine), create parallel GitHub issues per option (e.g., #2754 for ace-linux-1, #2755 for ace-linux-2) with machine-specific labels rather than a single issue with all options. Enables per-machine async discussion and approval.
