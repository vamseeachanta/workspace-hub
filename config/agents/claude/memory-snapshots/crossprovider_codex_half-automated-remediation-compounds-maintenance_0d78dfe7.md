When a tool lacks reliable version-pinning support (e.g., uv self update doesn't accept version arguments, apt versioning is loose), partial remediation creates debt and false coverage expectations. Choose: full automation via exact version-pinning channels, or audit-only with documented exceptions. Half measures don't scale.
