Worktree isolation patterns, lock/path traps, tool invocation quirks, verification gates, and uv/environment bootstrap lessons transfer effectively to fresh sessions when written to handoff prompts at discovery time. The lesson value is highest immediately after verification; documenting in handoff (not memory) ensures fresh-session visibility without requiring context-chain reads.
