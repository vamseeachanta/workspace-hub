Migration-residue cleanup cannot determine safety by inspecting residue folders alone. Each residue row must be compared against an active counterpart: verify duplicate proof, retention obligation, backup snapshot, and owner approval on the pair, not the folder in isolation. One shared header value across a pair cannot serve as duplicate evidence.
