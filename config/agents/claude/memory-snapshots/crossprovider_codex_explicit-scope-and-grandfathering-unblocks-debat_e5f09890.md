When adding features on top of existing production systems, explicitly call out what behavior is grandfathered (existing, unchanged) vs. newly added. Example: 'existing `gmail-archive-extract.py` performs Gmail delete/review routing for months; #2017 adds only state-tracking on top.' This resolves scope creep debates fast.
