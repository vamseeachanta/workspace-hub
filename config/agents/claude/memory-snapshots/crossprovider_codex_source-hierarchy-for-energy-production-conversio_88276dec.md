Conversion factors (bbl/tonne, API gravity) must come from primary sources: regulator production reports, operator filings, technical assays, or same-period tonnes-plus-barrels derivations. Trade tables (OGJ Worldwide Production) are acceptable only as reference leads, not as conversion drivers. Secondary sources and derived values fail-closed.
