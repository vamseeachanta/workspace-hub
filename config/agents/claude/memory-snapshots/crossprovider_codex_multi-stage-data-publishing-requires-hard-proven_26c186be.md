Each artifact must carry source class, license/terms, derivation path, and reviewer decision BEFORE publication. Stage gates require explicit promotion criteria. Ledgers need public/private partitions to avoid leaking sensitive metadata. 'All-available' first bundle is too risky with mixed sources.
