Plans must demonstrate they fix the stated issue, not just move toward it. If the issue demands 'job succeeds', acceptance criteria must require the exact success condition (exit 0), not approximations like 'reduced errors'. Acceptance criteria must match the issue's actual success state, not a weaker proxy.
