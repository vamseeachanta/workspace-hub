Plans fail MAJOR when they (1) bundle disparate work without justifying cohesion (e.g., platform-entity + overview refresh + stability-in-waves as one issue), (2) miss required evidence sources (knowledge/intelligence issues must cite operating model; docs issues must cite governance surfaces), (3) have weak test contracts (e.g., "count files" without verifying immutability under concurrent landings).
