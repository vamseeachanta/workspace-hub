When generating exit handoffs for multi-session work (e.g., repo spinouts), document the approval-gated issue inventory, scorecard/anchor issues, and boundaries (raw-data exclusions, vendor-derivative restrictions). This locks in governance so next sessions inherit constraints and avoid re-discovery.
