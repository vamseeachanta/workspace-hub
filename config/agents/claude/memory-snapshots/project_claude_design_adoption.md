## Brand hierarchy — locked 2026-04-21

**Why:** Discovered during #2435 trial that nav.html had only an inline-SVG "A&CE" placeholder wordmark, no real logo asset, and four concurrent brand treatments with no documented precedence. User decision resolved the ambiguity.

**How to apply:** When writing new copy, design work, or marketing content for aceengineer-website:

- **Consumer-facing** (site nav, marketing, social, design system lockup): `AceEngineer` (single word, informal)
- **SEO / accessibility** (SVG `<title>`, meta-description): `Analytical & Computational Engineering`
- **Legal only** (tax docs, contracts, bank forms): `Achanta AceEngineer Inc.` (Houston TX entity)
- **Retired — do not use in new work**: `A&CE`
