A playbook, skill, or artifact can pass strict schema validation while making claims that diverge from ground truth or the underlying implementation. Verify both: schema conformance AND factual accuracy against the source artifacts/campaign/real behavior. Schema checks do not catch overclaims or mischaracterizations.
