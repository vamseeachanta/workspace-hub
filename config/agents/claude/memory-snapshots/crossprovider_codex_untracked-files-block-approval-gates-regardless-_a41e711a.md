Untracked `.md` and `.py` files in public locations fail `scripts/legal/legal-sanity-scan.sh --diff-only`, even if content passes explicit public-surface scans. Generated bytecode (`__pycache__/`) from validator runs also triggers this gate. This is a hard technical blocker; files must be tracked or removed before approval can proceed.
