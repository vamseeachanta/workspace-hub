Plan reviews conducted against text alone—without access to actual repository files, schemas, and issue state—cannot empirically verify citations to code paths, schema fields, or API contracts. Plans referencing remote artifacts should include verification evidence (file excerpts, schema proofs, command outputs) or flag the review as constrained by lack of direct access.
