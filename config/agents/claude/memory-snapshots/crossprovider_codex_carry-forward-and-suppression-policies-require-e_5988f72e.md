In recurring audit reports, vague carry-forward instructions ('unchanged items not surfaced as new') create ambiguity that causes weekly churn. Explicitly define: are unchanged items hidden, summarized in a stale section, counted toward trends, aged with a freshness indicator, or shown separately? Each choice changes operational utility.
