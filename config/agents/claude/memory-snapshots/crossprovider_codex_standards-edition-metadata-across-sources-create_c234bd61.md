When standards appear in multiple sources (publisher catalog, local holdings, design registry), versions diverge materially: DNV-RP-C203 shows 2024-10 amended 2025-10 in official catalog, 2016-04 in registry, and only 2000–2011 editions in local storage. Local inventory cannot serve as currentness authority; publisher metadata alone is insufficient to validate formulas/constants. Requires qualified reviewer gatekeeping for any standards-derived calculation.
