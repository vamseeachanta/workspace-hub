PDF ingest often misfiled by source folder (e.g., 'ISO/flag-state-performance.pdf' is maritime-law, not ISO-standards; property drawings and personal scans end up in O&G-Standards folders). ALWAYS classify by extractable content and route to the correct domain; folder label is misleading.
