Scan job postings to identify skill demand (e.g., 131 open roles mentioning cathodic protection), then use scores to prioritize MODULE-level builds within existing packages rather than full feature completion. This reframes development from 'feature complete' to 'highest-impact subset that matches hiring signals.' For ACE Engineer, it means CP package goes from 15→18 modules (anode_sizing, pipeline_cp, marine_cp) based on job demand, not architectural completeness.
