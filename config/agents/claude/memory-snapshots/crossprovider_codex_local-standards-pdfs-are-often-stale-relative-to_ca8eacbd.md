Edition mismatches are common: wiki pages claim current publisher versions (e.g., API Spec 4F 5th Ed 2023) but local copies are older (4th Ed 2013). Plans must verify local PDF title pages and publication dates against claimed content before accepting page citations. Source provenance audits must distinguish local available edition from current public edition.
