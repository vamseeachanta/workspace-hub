When building compliance audits, define a three-tier evidence model: authoritative (e.g., session transcripts, hook logs), secondary (e.g., plan artifacts matching naming convention), and tertiary (e.g., commit metadata). Fallback chains prevent overweighting weak evidence and clarify what to do when authoritative evidence is absent.
