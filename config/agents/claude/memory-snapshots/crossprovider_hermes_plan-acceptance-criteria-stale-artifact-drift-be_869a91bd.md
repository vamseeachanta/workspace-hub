When plans evolve through version bumps (v3→v4) and shift wave labels, acceptance criteria can reference outdated artifact versions from prior review rounds. Governance reviews must verify acceptance criteria use fresh current-draft artifacts, not stale evidence, or approval gates become non-canonical.
