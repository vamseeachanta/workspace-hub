ABS Rule Manager requires MyFreedom portal registration for full access (personalized books, offline access, enhanced search). Plans acknowledging this gating but not converting it into explicit acceptance criteria (e.g., 'MyFreedom features out of scope' vs 'manual only' vs 'authentication/automation required') leave implementation scope ambiguous. Access limitations should be stated as scope boundaries, not just acknowledged risks.
