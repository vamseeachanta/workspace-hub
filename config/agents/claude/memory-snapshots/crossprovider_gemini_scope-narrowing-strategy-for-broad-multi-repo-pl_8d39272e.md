When a planning issue spans multiple repos/tiers and fails adversarial review as too broad, narrow it to a single-repo scope first (e.g., workspace-hub-only), define that as canonical, then use it as a base for later tier-1 work. This makes issues approvable and provides reusable scaffolding without scope creep.
