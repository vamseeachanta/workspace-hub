Initial governance plans used placeholder `grep` patterns and bare issue numbers. Adversarial re-review forced concrete touched-file paths (e.g., `TOUCHED='docs/governance/<target>.md'`), repo-qualified issue refs (e.g., `vamseeachanta/llm-wiki#43`), and executable bash commands. Pattern reinforces: plan artifacts must be executable without guessing.
