/mnt/ace uses "0NNN Project Name" convention across both docs/projects and client-c (86 + 53 dirs respectively). Allows sorting by number, grouping (0000-0999, 1000-1999), and simple 3-digit addressing. Paired with alphabetic project names for human readability. When designing new project catalogs, this pattern scales well.
