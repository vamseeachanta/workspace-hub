Plans frequently defer scope to sibling/dependent issues (e.g., 'this is handled by #605') without pulling those issues' actual plans and verifying their acceptance criteria cover the deferred scope. Textual deference is not verification; when a plan says issue X owns a scope, inspect X's plan and acceptance criteria to confirm they address it.
