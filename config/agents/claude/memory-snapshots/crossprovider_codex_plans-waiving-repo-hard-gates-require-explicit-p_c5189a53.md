When a plan claims an exception to a repo hard gate (e.g., "TDD mandatory with no exceptions" in AGENTS.md), the plan cannot self-waive it. It must cite an approved policy, issue, or governance decision that authorizes the exception. Phrases like "infrastructure work, no TDD required" are assertions, not approvals.
