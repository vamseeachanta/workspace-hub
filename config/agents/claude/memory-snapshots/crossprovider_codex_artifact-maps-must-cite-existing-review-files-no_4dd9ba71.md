Approval gates verifying cross-provider evidence require that cited artifact paths actually exist and match dates. Maps listing nonexistent files (e.g., claiming '2026-04-29-plan-*.md' when actual is '2026-04-30-...md') are MAJOR blockers. Artifacts must be retrievable; promise-based maps fail verification.
