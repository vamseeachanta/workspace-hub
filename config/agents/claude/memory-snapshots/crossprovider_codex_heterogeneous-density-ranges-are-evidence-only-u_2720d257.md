A field's API range (e.g., 20–39 API) cannot justify a single conversion factor without explicit reserves weighting, production weighting, or field-average source. Arithmetic midpoint proxies must be labeled derived and never treated as conversion-ready without source-stated weighting. This distinction separates evidence (range) from acceptance (representative).
