Adversarial reviewers consistently caught that plan-cited evidence (file paths, test names, existing script capabilities) requires live verification before trusting. Multiple rounds of the same plan review caught different defects when each reviewer actually ran `grep`, `find`, and `ls` instead of trusting plan text. Plan evidence quality is load-bearing for governance approval; citations must be empirically verifiable, not aspirational.
