An issue can be `status:blocked` in GitHub but be most actionable if local evidence is packaged: ready issue drafts, dispatch prompts, batch metadata, and filing packets. Parent blocker analysis should inventory local readiness artifacts (docs/reports/issue-drafts, dispatch-prompts, filing-packets) alongside issue labels to prioritize next work.
