Plans claiming data from external sources without resolvable identifiers (e.g., 'OTC papers', 'if present', 'to be determined during implementation') fail verification. Every cited source must include DOI, stable URL, document ID, or other persistent reference; vague or deferred sourcing creates reproducibility gaps.
