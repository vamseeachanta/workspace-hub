Narrative descriptions like 'aggregate-only' or 'opaque' enable disagreement about what's forbidden. Concrete types, allowed values, field constraints, nullability, and tuple structure enable testable validators and scanner rules. Informal specs cause validation gaps that survive testing until diff review.
