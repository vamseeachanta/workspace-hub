Generate mesh families at density levels [0.25x, 0.5x, 1x, 2x, 4x] from a single source mesh (via refinement/coarsening) to enable convergence studies in diffraction analysis. Pair each member with quality metrics (area, aspect ratio, degenerate count) for reporting and validation.
