When multiple plans in the same implementation wave will interact or merge outputs, coordinate data structure vocabulary, scoring rubrics, and schema upfront to ensure merge-compatibility. Sibling plans using incompatible vocabularies create silent serialization mismatches. Example: wave-2 and wave-3 knowledge promotion plans must share identical `{candidate, reviewed, promoted, rejected}` status vocabulary and 0-3 scoring rubric.
