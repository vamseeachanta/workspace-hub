Never commit vendor standards PDFs, copied clause/table/formula excerpts, client/project docs, or private archive contents to public repos. Commit only source-family labels, metadata pages with original synthesis, and refs to external licensed locations. Standards-derived data stays as pointers with digest/checksum only.
