GPLv2, GPLv3, and linking exceptions are not interchangeable in license fields. Capture exact version (e.g., GPLv3-or-later vs GPLv2-or-later) and linking-exception terms explicitly; collapsing to 'GPL' masks dual-license conflicts and violates SPDX precision.
