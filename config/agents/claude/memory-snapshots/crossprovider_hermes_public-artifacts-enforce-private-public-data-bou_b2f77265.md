Public repo roadmaps and scorecards avoid raw /mnt/ace paths and vendor-specific intel. Private data routes to off-repo documentation paths (e.g., /mnt/ace/docs/). Public-safe summaries and links go to canonical repo locations. Prevents accidental leakage of proprietary source family data.
