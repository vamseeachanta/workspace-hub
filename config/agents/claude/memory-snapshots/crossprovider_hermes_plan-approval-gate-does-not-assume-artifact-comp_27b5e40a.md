APPROVE verdict on a plan does not mean external resources (wiki pages, off-repo data access, citation targets) already exist. Phase 0 can be responsible for locating or creating those as fail-closed prerequisites. Approval means the plan boundary and fail-closed gates are sufficient; execution gates remain.
