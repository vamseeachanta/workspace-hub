Engineering standards are classified by discipline and routed to specific repositories (digitalmodel, worldenergydata, assethold, lng-a, OGManufacturing, mkt-a, client-d, client-b) based on relevance. Example: cathodic-protection and corrosion standards → assethold/digitalmodel; structural analysis → digitalmodel/mkt-a; pipeline welding → relevant ops repos. Selecting repos requires domain judgment, not automatic categorization.
