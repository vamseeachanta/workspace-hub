For encrypted, image-only, or off-scope PDFs, create a metadata-only resolver entry (code_id, publisher, revision, source location, license_status) rather than an empty entry or skip entirely. This signals the document was identified but not ingested, preserving its discovery path for future inspection or decision-making.
