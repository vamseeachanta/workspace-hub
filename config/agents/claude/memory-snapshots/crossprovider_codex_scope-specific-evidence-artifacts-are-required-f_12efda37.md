Dependency Matrix and Evidence sections that cite issue states or prior artifacts must include committed evidence paths or immutable references, not just prose assertions. If a plan depends on external state (issue status, prior artifact), include a concrete evidence file path in repo or acknowledge the dependency as a pre-implementation assumption requiring external verification.
