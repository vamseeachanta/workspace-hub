Engineering-first GTM scope/method notes (FOWT, installation-analysis) must distinguish current screening capability from deferred fidelity upgrades (WEIS/OpenFAST), ground in existing resources, and explicitly state cannot-claim-yet boundaries. Prevents over-claiming certification-grade capability and sets buyer expectations correctly.
