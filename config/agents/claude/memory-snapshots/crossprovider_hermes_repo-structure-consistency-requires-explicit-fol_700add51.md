After completing a multi-machine story (e.g., ace-linux-1 tier-1 baseline), create formal GitHub issues per machine (ace-linux-1-tier1-repos, ace-linux-2-tier1-repos, licensed-win-1-tier1-repos) to decide tier-1 placement and standardize folder structure. Leaving this as implicit post-work cleanup gets deferred indefinitely.
