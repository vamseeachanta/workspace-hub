/mnt/ace/O&G-Standards (38GB) organized by standards org: API, ASTM, ISO, BSI, DNV, SNAME, MIL, OnePetro, ABS, NEMA, Norsok, plus raw/ (20GB unsorted) and Unknown/ (3.3GB). Accompanied by _inventory.db (6.8GB SQLite), _catalog.json (19.5MB), _ocr_text/ (81MB extracted text). This structure mirrors the standards-transfer-ledger org field and enables bulk discovery by organization. When querying standards, check both catalog files and inventory.db.
