Organize extraction skills into three layers: Layer 1 (generic content types: constants, equations, tables, procedures), Layer 2 (engineering patterns: unit normalization, source tracking), Layer 3 (domain sub-skills per standard: DNV-RP-B401, API RP 16Q). This layering enables heuristic reuse across multiple standards and domains.
