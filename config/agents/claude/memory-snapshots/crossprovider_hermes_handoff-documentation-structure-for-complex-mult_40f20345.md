For engineering tasks spanning multiple parallel agent sessions (e.g., SIROCCO report refinement), comprehensive handoff must include: restart objective, verified current artifact state, recommended modifications with pseudo-code, execution/validation steps, and copy/paste restart prompt. Incomplete handoffs caused 4+ failed resume attempts; complete structure enabled clean handoff to parallel sessions.
