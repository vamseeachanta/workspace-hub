When organizing agent skills, consolidate narrow overlapping skills into class-level umbrellas with labeled subsections, not separate one-session-one-skill micro-entries. Hard rules: never delete (archive to .archive/ instead), never touch pinned skills, merge pairwise overlapping pairs into one umbrella with subsections/references/templates/scripts/ support files.
