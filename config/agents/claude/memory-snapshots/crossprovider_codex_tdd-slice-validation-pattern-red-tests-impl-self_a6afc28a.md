Incremental TDD: (1) Write divergence/baseline tests (RED). (2) Implement minimal scope slice. (3) Self-review classification (PASS/MINOR/MAJOR). (4) MAJOR findings block commit. (5) Commit and push per complete slice. Per-slice validation prevents accumulating unvalidated changes.
