Treat all plan-cited facts (file paths, counts, behavior, tool invocations) as assertions to verify, not established facts. Each finding must cite specific evidence; unsourced critique gets stripped. Default to MINOR or MAJOR when uncertain; APPROVE only after affirmative verification of correctness-critical claims.
