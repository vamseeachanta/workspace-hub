Approval-gate review artifacts (for moving plans to status:plan-review) cannot be auto-generated by repository scripts. Operator must manually save latest non-empty fanout stdout from provider reviews with reviewed-commit and plan-SHA256 metadata as a pre-approval prerequisite; this is governance, not a code deliverable.
