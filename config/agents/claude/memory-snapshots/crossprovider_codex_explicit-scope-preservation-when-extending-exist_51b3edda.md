When planning features that extend existing audit/telemetry/reporting systems, explicitly state what existing behavior to preserve vs what to add. Cite the existing code/artifacts that should be extended rather than inventing duplicate sources. Scope should separate in-scope-now, explicitly-out-of-scope, and future-issues into distinct sections.
