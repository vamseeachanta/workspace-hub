Labeling a BM25 (keyword-based, lexical) search as 'Semantic Search' misleads users expecting vector/synonym/conceptual matching. Use precise naming: 'keyword search', 'lexical search', or 'vector-based semantic search'. Documentation accuracy prevents user confusion and support burden.
