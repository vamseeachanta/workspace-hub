For prospect outreach (e.g., Scott Sanantonio), store only public LinkedIn URL and user-supplied planning context in Git. Never commit private emails, phone numbers, or contact details. If user supplies role history, treat as user-supplied context; recheck independently before personalization. Do not send email until user approves final email + collateral packet.
