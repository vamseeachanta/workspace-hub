Classify repo/workspace cleanup state into four buckets: CLEAN (safe to ignore), EXPECTED (acceptable, documented), UNEXPECTED (needs review), and DEFER (needs owner/stakeholder confirmation). This taxonomy surfaces decisions that cannot be made unilaterally and prevents premature deletion of shared resources.
