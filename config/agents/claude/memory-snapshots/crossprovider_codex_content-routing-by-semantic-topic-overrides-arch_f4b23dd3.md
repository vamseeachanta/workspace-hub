PDF folder placement (API, ISO) does NOT dictate ingest domain. A standard's actual topic (e.g., metocean design in an API-folder PDF) routes to its semantic domain (marine-engineering, not engineering-standards). Prevents misclassification when PDFs are archived by source rather than subject.
