Classify synthesis decisions as CONSENSUS (all agents agree), SPLIT-MAJOR (divergence requiring user resolution), SPLIT-MINOR (minor/stylistic differences that proceed), or SOLO (outlier agent). Only SPLIT-MAJOR decisions block the pipeline; minority dissenting views must be reported regardless to prevent systematic bias.
