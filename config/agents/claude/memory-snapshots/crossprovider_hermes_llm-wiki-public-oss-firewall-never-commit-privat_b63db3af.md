Public repo commits/issues must exclude private workspace memory, recruiter notes, vendor-derivative content, credentials, tokens, passwords, raw/private archive data. Input boundaries only (/mnt/ace, private repos). Output is MIT for code, CC-BY-4.0 for content. Service-provider data routing enforced via docs/governance/service-provider-data-routing.md.
