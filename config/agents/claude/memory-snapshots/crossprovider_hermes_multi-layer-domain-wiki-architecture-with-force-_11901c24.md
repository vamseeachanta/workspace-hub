Organize wikis as multi-domain ecosystem under knowledge/wikis/<domain>/ with three layers per domain: raw (immutable source), wiki (agent-maintained markdown), schema (CLAUDE.md rules). Force-add wiki pages to git despite .gitignore since wiki content is compounding artifact. Cross-link topics across domains.
