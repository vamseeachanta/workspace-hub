Binding SHA-256 hashes for "normalized RAO" or "conventions" allows two backends to satisfy the hash gates while computing physically incompatible quantities if the canonical equations (wave height vs amplitude, Hz vs rad/s, rotation order, frame assumptions) are never written. Hash contracts need grounding in explicit physics/semantics.
