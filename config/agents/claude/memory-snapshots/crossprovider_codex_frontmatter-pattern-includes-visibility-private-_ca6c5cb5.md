Core frontmatter keys for all pages: code_id, publisher, revision, jurisdiction, visibility (private-llm-wiki), source_pdf (off-repo), license_status (e.g., 'copyrighted-bsi-standard', 'encrypted-metadata-only'), parse_status. NO extraction_policy or raw_copy_allowed fields. This signals public-safe vs. private boundaries.
