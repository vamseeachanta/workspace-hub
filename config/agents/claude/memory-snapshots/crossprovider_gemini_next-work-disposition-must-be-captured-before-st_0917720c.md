Before Stage 17 (user review of implementation), any 'next work' identified during execution must be explicitly captured via either updating an existing WRK or spinning off a new one, with disposition recorded in evidence. Items identified but not captured must be cleared before Stage 17 closure. Use a Captured column (yes/no) in markdown tables and YAML evidence artifacts to track this.
