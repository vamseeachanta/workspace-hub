File byte counts, counts of major entries (e.g., '60 routing rules, 17 DELETE, 9 REVIEW'), commit dates, and file sizes in resource sections prevent hallucination and aid scope estimation. Bare existence claims ('Exists: email-routing.yaml') are insufficient. Observed in #2017 resource intelligence pattern.
