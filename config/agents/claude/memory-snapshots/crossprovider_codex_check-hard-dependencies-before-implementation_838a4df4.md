Do not begin implementation if a hard-dependency issue has not yet produced required decisions or artifacts. Instead, collect no-code blocker evidence and post a status comment naming the missing artifact (e.g., chosen model, completed scaffold, credentials). Prevents false starts and focuses effort on unblocked work.
