GitHub issues about 'weekly' or 'recurring' work should explicitly state that scope and list cron-readiness as a non-optional deliverable, not a side effect. One-off cleanup issues that claim weekly focus without cron deliverables drift into ad-hoc maintenance. Make the scheduling explicit.
