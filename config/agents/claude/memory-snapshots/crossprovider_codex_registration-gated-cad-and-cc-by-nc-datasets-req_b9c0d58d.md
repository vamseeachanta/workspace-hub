Publicly visible geometry (e.g., TUM DrivAer STEP/STL) may have registration-gated terms prohibiting third-party transfer and requiring written permission, despite appearing open. Loughborough experimental datasets (CC BY-NC 4.0) explicitly forbid commercial use without permission. Visibility ≠ reuse-clear; obtain written permission before any client delivery. Licensed alternatives (DrivAerML, AhmedML, WindsorML all CC BY-SA 4.0) allow attribution-only commercial reuse.
