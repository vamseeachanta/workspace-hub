When consolidating duplicate skills from different providers (Hermes vs repo), Hermes versions typically contain more complete operational content (workflows, examples, decision rules) while repo versions have better structural metadata (frontmatter, categories). Strategy: use Hermes as canonical base for content, then retrofit repo metadata.
