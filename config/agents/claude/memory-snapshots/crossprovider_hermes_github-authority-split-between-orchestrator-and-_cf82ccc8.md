Execution orchestrator (central) and delegated teams (agents) must have explicit GitHub posting/check-in ownership: orchestrator owns issue start/final close, delegated teams own stream progress/results. Posting ownership prevents duplicate/conflicting updates and clarifies accountability. This must be stated in handoff contracts and execution start comments.
