Architecture contracts (data-layer-contract.md) explicitly forbid silent moves of canonical tier-1 repos (workspace-hub, digitalmodel, worldenergydata, llm-wiki). Any repo placement change requires an open GitHub issue, plan review, and user approval. This governance rule is load-bearing and non-optional.
