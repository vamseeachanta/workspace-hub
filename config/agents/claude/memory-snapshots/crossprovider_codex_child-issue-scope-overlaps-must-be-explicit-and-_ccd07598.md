When two child issues both claim to handle a domain (e.g., both #265 static and #269 databases claim to inventory sources), the plan must clearly state which is primary and whether there is a sequencing gate. Live #265 saying "codes, rules, guides, guidance notes, databases" while #269 also covers databases creates ambiguity. Define non-overlapping scope or explicit dependency gates.
