Plans that embed inline 'Review artifacts:' metadata become stale during multi-round adversarial review cycles, as each new round invalidates the embedded list. Findings across multiple review rounds consistently flag 'stale review artifact inventory' as a blocker. Maintain review round history in external artifact logs separate from plan documents.
