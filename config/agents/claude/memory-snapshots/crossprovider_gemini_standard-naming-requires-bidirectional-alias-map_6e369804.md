Engineering standards are referenced by multiple name forms (e.g., 'DNV-OS-F101', 'dnv os f101', 'dnv-os-f101', 'osf101', 'f101'). Text-based search for standards must map the canonical form to all common aliases; scoring algorithms should check matches against the full alias set.
