Plans undergoing multiple adversarial review rounds (3+) with findings decreasing and resolutions improving per round is normal behavior; it demonstrates the review-refine-resubmit cycle working correctly. Distinguish genuine refinement (scope clarification, defect fix) from sustained-major loops (three+ rounds with equally-blocking findings), which may signal plan-scope misalignment.
