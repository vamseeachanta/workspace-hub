Plans list acceptance criteria that are non-testable ('Review artifacts posted', 'documented in plan') or incompletely mapped in AC↔Test matrices. This allows unverified AC to slip through. Every AC must have a corresponding executable test, enforcement check, or explicit 'manual-verification-during-implementation' note.
