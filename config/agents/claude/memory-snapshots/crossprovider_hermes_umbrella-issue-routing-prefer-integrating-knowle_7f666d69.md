When creating follow-up issues for knowledge-work gaps (standards summaries, entity coverage, wiki sections), prefer adding to existing umbrella/roadmap issues (e.g., #2390 for llm-wiki strengthening) over creating parallel issues. Requires evidence-based duplicate detection: inspect live issue state and planning docs before creating any new issue.
