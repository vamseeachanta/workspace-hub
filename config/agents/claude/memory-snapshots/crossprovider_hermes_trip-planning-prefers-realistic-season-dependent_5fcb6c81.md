For GitHub-based trip planning (achantas-data repo), users prefer realistic photos showing each season (spring, summer, fall, winter/off-season), not marketing-curated images. Seasonal expectations matter: tulip-season routes are historical/transient, Florida water color varies by weather, Galveston is coastal not Florida-style, waterfalls depend on rain levels. Use GitHub issues + comments for photo previews to help travelers choose weekend destinations without false expectations.
