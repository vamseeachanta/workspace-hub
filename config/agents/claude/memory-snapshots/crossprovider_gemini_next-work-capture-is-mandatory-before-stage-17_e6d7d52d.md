Any 'next work' discovered during implementation (stages 1-15) must be formally captured before Stage 17 (User Review - Implementation) using one of two paths: update an existing WRK or spin off a new WRK. Disposition must be recorded in `assets/WRK-<id>/evidence/future-work.yaml` with explicit `captured: yes/no` column in markdown artifacts.
