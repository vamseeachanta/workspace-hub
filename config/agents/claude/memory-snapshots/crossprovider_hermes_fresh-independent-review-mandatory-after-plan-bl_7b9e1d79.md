Plan revisions cannot reuse prior or delegate review artifacts. After blocker-remediation patches, must re-run full adversarial review with independent reviewers. Circular reuse (e.g., 'prior Hermes review is sufficient') is rejected by governance gates as insufficient. Only fresh review → no MAJOR findings allows promotion from blocked status.
