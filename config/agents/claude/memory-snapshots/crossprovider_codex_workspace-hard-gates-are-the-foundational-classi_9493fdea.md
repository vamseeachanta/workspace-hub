Every work item must be classified against the gate sequence: Issue → Plan → User Approval → Implement → Cross-review → Close. No issue can be classified as execution-ready without evidence satisfying BOTH the approval-label requirement AND the local marker requirement. This gate is non-negotiable for audit scope.
