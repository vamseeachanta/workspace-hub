Spec files using random-generator names (e.g., 'iridescent-dreaming-kazoo') have zero semantic meaning, forcing agents to open every file to understand content. Renaming to domain-topic kebab-case (e.g., 'ace-gtm-group-tagging') enables grep-based discovery and human browsing. Established naming convention: specs/wrk/WRK-<id>/<kebab-topic>.md and specs/repos/<repo>/<kebab-topic>.md.
