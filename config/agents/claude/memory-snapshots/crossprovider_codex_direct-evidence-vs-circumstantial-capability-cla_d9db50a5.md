Direct evidence (contract, PO, job file, case study) proves prior engagement; generic technical files (offshore riser handling, fabrication standards) are circumstantial. Bounded search finding nothing = verified gap in the searched scope, not prohibition on engagement elsewhere. Evidence hierarchy prevents capability-assumption carryover.
