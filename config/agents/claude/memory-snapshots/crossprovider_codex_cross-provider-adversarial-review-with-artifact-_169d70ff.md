Plans are reviewed by multiple providers (Claude, Codex, Gemini, Hermes) across iterative rounds; each round's review artifacts are archived with version suffix (e.g., `plan-r1.md`, `plan-r2.md`) while current round remains canonical (e.g., `plan.md`). MAJOR findings trigger patches and re-review.
