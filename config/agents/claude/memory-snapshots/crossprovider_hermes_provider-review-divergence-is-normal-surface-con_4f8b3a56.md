Codex and Claude reviewers on the same artifact often find different defects (non-overlapping root causes). Neither alone is complete. Before approval gate, synthesize findings into: defects all reviewers agree on (high confidence), defects some reviewers flagged (medium confidence), and defects found by only one provider (flag for double-check).
