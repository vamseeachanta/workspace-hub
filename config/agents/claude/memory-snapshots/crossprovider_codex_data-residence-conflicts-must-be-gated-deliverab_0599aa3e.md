Acknowledging stale or conflicting data-residence docs in a plan's resource intel but only patching one file and deferring reconciliation to follow-on work leaves plans publishing readiness against a known-wrong residence model. Conflicts should either be corrected in-plan or made hard acceptance criteria requiring explicit follow-on tracking.
