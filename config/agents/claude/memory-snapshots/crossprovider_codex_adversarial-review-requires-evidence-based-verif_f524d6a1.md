Each plan claim must be verified against actual repo state, live GitHub metadata, and tool behavior—not accepted from the plan text. Treat all assertions as hypotheses to verify, not facts. Citations are mandatory; don't praise; focus only on what's wrong, missing, or risky. Empty reviews are failures.
