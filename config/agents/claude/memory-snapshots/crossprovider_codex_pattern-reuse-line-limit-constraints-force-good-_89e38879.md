When implementing similar features, study existing analogous modules (e.g., `worked_examples.py`, `sn_comparison_report.py`) to mirror structure and conventions. Artificial constraints on file/function size (e.g., 400 lines, 50 lines per function) prevent over-engineering and force clean decomposition.
