Established by issue #2511, the semiconductor domain now uses: `scripts/semiconductor/` for implementations, `tests/semiconductor/` for tests, `data/semiconductor/` for artifacts, and `docs/reports/` for portfolio documentation. New semiconductor work should follow this structure.
