Data output routing: public-domain federal data lives in `worldenergydata-wiki/wiki/<agency>/` (BSEE/NOAA); private synthesis in `llm-wiki/wikis/<domain>/`; client/project outputs in `llm-wiki-<client>/projects/<project>/`. Mixed analyses combining federal data with vendor standards or client context route private by default.
