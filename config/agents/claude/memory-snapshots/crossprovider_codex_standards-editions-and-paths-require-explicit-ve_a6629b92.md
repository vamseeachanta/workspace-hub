Plans that cite standards (API RP 14C, ISO 21457, NACE specifications) must verify current edition and path names. When standards are renamed (NACE→AMPP in 2024+) or split across editions, the plan's fact-check flagging should force user follow-up rather than assuming the stated edition is current.
