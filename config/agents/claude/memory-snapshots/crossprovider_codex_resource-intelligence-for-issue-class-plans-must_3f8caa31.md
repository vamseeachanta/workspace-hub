When a plan defines downstream contracts tied to other issues, issue titles/status/links are insufficient. Extract and cite specific acceptance constraints, decisions, and failure modes from linked issues. Example: #2975 plan references #2968-72 but only notes they 'carry tightened decisions' without stating what those decisions are.
