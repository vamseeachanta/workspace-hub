Governance artifacts should include required-field checklists (candidate ID, source-family label, license class, client-sensitivity flag, allowed-vs-disallowed evidence sections) before extraction work begins. Checklist enforces explicit approval and boundary declaration, preventing accidental vendor/client/private material ingestion.
