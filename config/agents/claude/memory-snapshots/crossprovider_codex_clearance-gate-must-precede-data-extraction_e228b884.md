Clearance for extracting content (standards, vendor material, client deliverables) must be obtained BEFORE extraction, not as post-condition. Tests must fail if clearance record is absent or if prohibited content persists. Applies broadly to data extraction, knowledge-base curation, and IP-sensitive work.
