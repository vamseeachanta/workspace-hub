Plans asserting 'Found: <file>', 'Related issue #NNNN', 'Consulted: <standard>' without proof fail the mandatory resource-intelligence check. Every claim in the Resource Intelligence Summary must cite a concrete file path, issue URL with status, or document with a DOI/link, or be downgraded to 'assumption needing verification'.
