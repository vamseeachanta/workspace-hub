Single-pass plan reviews miss structural issues. Multi-round adversarial iteration (r1→r2→r3→r4) progressively uncovers blockers in different categories: source-of-truth ambiguity, test contract migration, file-map incompleteness, decision correctness. Each round catches what prior rounds did not.
