When issue N is blocked by issue N-1, the predecessor's approved plan often specifies target file paths and metadata structure (e.g., #627 inherits wikis/salesforce/wiki/overview.md and concepts/salesforce-software-ops-glossary.md from #625 plan). Read the predecessor plan to avoid re-designing structure.
