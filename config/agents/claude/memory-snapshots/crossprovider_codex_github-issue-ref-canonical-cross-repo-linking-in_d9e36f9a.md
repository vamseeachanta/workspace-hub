When WRK items map to GitHub issues on a different repo (e.g., workspace-hub WRK → digitalmodel issue), record the full issue URL in the WRK frontmatter github_issue_ref field. This is the durable, machine-readable link. Direct issue URLs are more reliable than gh searches when cross-repo issues are involved.
