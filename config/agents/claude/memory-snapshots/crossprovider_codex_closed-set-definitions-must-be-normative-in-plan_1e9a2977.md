When a plan requires enforcement of 'closed contexts,' 'allowed IDs,' or 'sentinel grammar,' the plan must include a normative definition table (exact values, enum, regex) with positive and negative test cases. Prose intentions like 'closed set of context IDs' are underspecified for implementation.
