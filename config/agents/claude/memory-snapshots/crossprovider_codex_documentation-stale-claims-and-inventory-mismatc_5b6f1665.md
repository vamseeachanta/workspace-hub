Stale paths, broken menu claims, and count mismatches (e.g., claiming 19 scripts when 20 exist) are treated as Critical/Important in review, not minor docs polish. Apply the same rigor: RED test (e.g., enumerate all files and verify the claim), minimal fix, independent review, commit.
