If a T2+ plan receives MAJOR from one provider and other providers return UNAVAILABLE, either rerun those providers after auth/access is restored or record an explicit governance degradation decision. Promoting to status:plan-review on unavailable artifacts weakens the multi-provider gate and creates approval opacity.
