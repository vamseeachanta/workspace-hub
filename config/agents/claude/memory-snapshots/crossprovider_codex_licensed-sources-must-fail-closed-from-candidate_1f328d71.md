Maritime and specialty manifests classify all unlocked PDFs as `full-fidelity-eligible` regardless of license class or public-domain candidacy. NAVSEA/USACE/licensed private sources must remain `licensed_*_only` or `public-domain-candidate` until per-file authorship and third-party content checks pass explicitly, not by default.
