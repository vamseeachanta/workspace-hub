When delegating work to agent teams, provide a structured pack: master-plan.md defining the overall scope, individual stream-<id>.md files with execution prompts (each self-contained), and execution-readme.md documenting integration points. Each stream requires a formal contract specifying objective, issue/sub-issue, allowed/forbidden/read-only paths, dependencies, and deliverables.
