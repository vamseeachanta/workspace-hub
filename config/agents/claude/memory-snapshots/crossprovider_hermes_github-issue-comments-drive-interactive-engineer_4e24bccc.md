For engineering-critical issues, post resource-intelligence comments (inventory/topology/state), then let interactive component-by-component discussion in comments establish decisions (forces, moments, sources, conventions). Comments become decision ledger; draft plan only after this phase stabilizes. Prevents parallel-work collision and creates audit trail.
