When a plan will consolidate distributed information sources (e.g., BUSINESS_BRAIN.md lists 4 repos, WORKSPACE_HUB_REPOSITORY_OVERVIEW.md claims 25), explicitly state how the implementation treats conflicts: use one as authoritative, merge both, mark one as incomplete, or separate into tiers. Silent omission of sources leads to incomplete artifacts and future discovery friction.
