Technical handovers often explain code, but the actually non-rediscoverable insights are the environment/tooling/system traps discovered during work (e.g., NTFS-FUSE mount stalls git, CI title-validator patterns, external API failure modes). Documenting these traps explicitly is what makes a handover valuable; code explanation the next agent can derive from reading.
