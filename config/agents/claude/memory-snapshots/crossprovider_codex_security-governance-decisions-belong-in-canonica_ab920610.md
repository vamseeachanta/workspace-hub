Security runbooks, response templates, and external-interaction policies should be cross-referenced from centralized governance docs (e.g., TRUST-ARCHITECTURE.md, SESSION-GOVERNANCE.md) rather than siloed in isolated files. External contributor interactions are Category B/C gate points that benefit from a unified policy surface.
