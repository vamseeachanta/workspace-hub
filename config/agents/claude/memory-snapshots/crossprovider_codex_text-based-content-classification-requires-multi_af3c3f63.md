Single-keyword filters for automated classification (resume/real-estate/financial) produce false positives on legitimate standards and technical papers. Require strong/multiple signals (e.g., title contains both 'yachting' AND 'resume', or specific footer text pattern). Be conservative: when in doubt, include the document.
