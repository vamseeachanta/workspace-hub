When planning work across multiple agents/providers, explicitly enumerate the finite set of agents at planning time (e.g., Claude, Gemini, Codex, Hermes) rather than defining "all agents" as an open set. Subsequent providers added after planning should trigger separate follow-up work, not retroactively expand the original issue's scope.
