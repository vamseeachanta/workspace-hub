Comparing RAOs across solvers with different water depth, center-of-gravity, or mass produces fundamental disagreement unrelated to interpolation or sampling. Grid alignment and overlap tests cannot repair physical input mismatch. Verify model parameters match before diagnosing discrepancies as numerical or grid issues.
