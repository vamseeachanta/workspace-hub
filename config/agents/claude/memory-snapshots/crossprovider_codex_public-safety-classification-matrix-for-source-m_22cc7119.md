Before promoting or extracting data from source archives, classify each source family into explicit buckets: (Safe now / Safe with care / Clearance-gated / Exclude). Failure to classify upfront leads to accidental exposure of client, vendor, or licensed material. Build the matrix as a durable artifact, not ad-hoc decisions.
