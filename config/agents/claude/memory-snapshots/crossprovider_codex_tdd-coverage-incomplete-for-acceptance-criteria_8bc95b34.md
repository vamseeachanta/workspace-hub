Acceptance criteria consistently lack corresponding test rows in AC ↔ Test Map (e.g., 'Review artifacts posted', 'Decision justified by numbers', 'Updated skill file landed'), and failure modes are often delegated to manual/reviewer-task rather than executable tests. Every AC must have a concrete test or be removed.
