Plans citing review artifacts as evidence (e.g., `scripts/review/results/2026-07-08-plan-X-codex.md`) must have those files present and valid. Missing or UNAVAILABLE artifacts are false claims; they block approval until real evidence lands. Header/body consistency on artifact status is load-bearing for the approval gate.
