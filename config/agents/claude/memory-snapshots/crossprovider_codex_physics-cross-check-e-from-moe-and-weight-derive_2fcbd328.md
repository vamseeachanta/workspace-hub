When validating rod properties, calculate sonic velocity as √(E/ρ) using cataloged modulus of elasticity and weight-derived density. This must reproduce the catalog's stated velocity (e.g., 16,300 ft/s) to within <1% error. If it does not, units are wrong—fix them rather than loosening the check.
