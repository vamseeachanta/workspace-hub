A unit-test fixture can verify chosen values match labels; it cannot prove an author did not derive them from withheld models or prior results. Synthetic/independently-authored work requires: access-separated roles, public input citations, generation rationale, authorship declaration, similarity/novelty review, and independent approval before publication. Fixtures alone are insufficient for publication gates.
