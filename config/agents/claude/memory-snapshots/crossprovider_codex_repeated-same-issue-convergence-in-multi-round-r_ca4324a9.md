When a plan receives 4+ review rounds and the same P1 issues surface (e.g., hook versioning, trigger mechanism) across different reviewers, the root architectural decision hasn't been validated. Dismissing as 'reviewer miss' wastes cycles; instead, halt and redesign that surface before proceeding.
