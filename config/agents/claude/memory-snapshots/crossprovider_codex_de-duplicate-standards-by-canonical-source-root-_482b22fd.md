Multiple storage roots often hold the same spec (e.g., /mnt/ace/mkt-a-codes/ASTM vs. /mnt/ace/O&G-Standards/ASTM). Create one source-ledger decision per code_id with canonical root assigned. Other roots become duplicate evidence, not separate pages. Prevents duplicate ingest across multiple issues.
