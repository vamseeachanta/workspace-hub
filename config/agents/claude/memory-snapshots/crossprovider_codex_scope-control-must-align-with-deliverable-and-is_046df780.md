Decomposition/inventory plans get incorrectly attached to 'fix the failing job' issues. If the deliverable is 'grouped inventory plus optional first slice', the plan must either split into separate issues or explicitly reframe the issue scope; it cannot hide that gap as 'out of scope for this issue'.
