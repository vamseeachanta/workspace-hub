When a page claims 'source-extract/quoted/nothing re-derived,' every numeric value must be directly verifiable in the source CSVs/extracts. Derived values (e.g., `920 * 0.2 = 184` computed contingency) must be explicitly marked as arithmetic, not presented as quoted source data. Use phrases like '920 × 1.2 = 1,104 (reconciliation)' to distinguish computed from sourced.
