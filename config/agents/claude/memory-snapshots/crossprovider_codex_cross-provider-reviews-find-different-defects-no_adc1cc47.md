Codex r2 reviews routinely surface defects Claude r1 single-author reviews miss. The structured output for cross-provider work must explicitly separate overlapping findings (consensus) from non-overlapping defects (Codex-unique or Claude-unique). Non-overlapping findings should be surfaced prominently because they represent actual value from multi-provider dispatch.
