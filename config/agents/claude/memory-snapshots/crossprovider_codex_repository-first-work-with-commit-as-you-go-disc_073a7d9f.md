Work in canonical repos on dedicated branches/worktrees, not `/tmp` staging areas. Keep durable artifacts in the repo; use `/tmp` only transiently for handoffs. Commit each approved, verified checkpoint with scoped pathspecs immediately. This preserves audit trail and prevents orphaned work.
