A handover's highest value is the environment traps and implicit assumptions that cannot be rediscovered from reading code: data modules breaking CI, mount-induced git stalls, domain conventions (not_public is a finding, not a failure). These load-bearing gotchas are what make handoff-to-agent work durable.
