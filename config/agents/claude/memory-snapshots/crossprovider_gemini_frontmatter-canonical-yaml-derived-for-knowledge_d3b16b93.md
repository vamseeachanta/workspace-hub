For knowledge artifacts at scale (468 skills), frontmatter metadata (capabilities, requires, see_also) is the single source of truth; derived outputs (SKILLS_GRAPH.yaml) are generated by script, not hand-curated. Prevents dual-write conflicts and maintains traceability. Sequencing: frontmatter → graph → indexes → README.
