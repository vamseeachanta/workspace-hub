For new engineering domains or projects, document discovery (e.g., standards, prior work, assumptions) in LLM wiki pages before creating implementation GitHub issues. Prevents scope creep, aligns cross-provider knowledge, and helps issue/plan writers establish clear boundaries and reuse existing context.
