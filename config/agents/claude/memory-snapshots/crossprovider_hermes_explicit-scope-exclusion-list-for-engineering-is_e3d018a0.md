When creating engineering-critical issues (e.g., naval arch force calculations): explicitly list physics/data topics that are excluded unless user re-approves (e.g., hull current force, bank effects, tug loads, mooring stiffness, propeller race, IMO compliance). Prevents scope creep and splits materially new physics into separate issues.
