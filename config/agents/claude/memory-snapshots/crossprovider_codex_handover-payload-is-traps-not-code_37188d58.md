A handover's highest-value content is the hard-won gotchas and non-obvious constraints—environment quirks (git stalls on NTFS-FUSE mounts), CI trap rules (data(cost): PR-title prefix breaks validation), semantic contracts (not_public rows are deliverables, not failures). Code the next agent can read; the traps it will rediscover only through costly failure.
