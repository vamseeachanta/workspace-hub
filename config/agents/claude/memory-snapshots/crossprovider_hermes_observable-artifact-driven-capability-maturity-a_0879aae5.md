Assess repository maturity (1=Nascent to 4=Mature) based on observable artifacts, not subjective judgment: README/CLAUDE.md presence (declared tier), module structure/tests/docs (structural tier), recent commits/scripts/data (behavioral tier). Classify by 7-domain taxonomy: ENG, DATA, WEB, BIZ, INFRA, KNOW, FIN.
