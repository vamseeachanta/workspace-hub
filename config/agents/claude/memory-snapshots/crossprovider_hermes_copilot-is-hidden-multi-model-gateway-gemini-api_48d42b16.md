GitHub Copilot ($9/mo) routes to 100+ models including Gemini 2.5-pro (via GH_TOKEN). Separate from Gemini API Direct ($20/mo GEMINI_API_KEY) and Google Cloud Console (pay-per-use). All three paths work but draw from different subscriptions — usage not consolidated. OpenRouter adds 4th path (free tier: qwen3.6, paid models: google/gemini-2.5-pro with credit top-up).
