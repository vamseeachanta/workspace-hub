For workstation repo placement/checkout normalization/registry decisions, create GitHub issues BEFORE clone/delete/relocate/sync operations. Post concise status comments capturing placement decisions (required repos, optional repos, excluded repos per machine). Stop BEFORE implementation approval gates. Issues serve as decision ledgers.
