Plans frequently embed claims about live issue states, file existence, prior review artifacts, and operating-model compliance as facts without providing independently verifiable evidence within the review artifact itself (e.g., no commit refs, no checked-in evidence files, no quoted standard text). These assertions must be replaced with verifiable repo-local evidence or removed entirely; embedded prose and grep snippets do not meet the verification bar.
