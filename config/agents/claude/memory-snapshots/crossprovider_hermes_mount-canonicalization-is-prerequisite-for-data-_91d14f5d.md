Before defining data promotion rules or repo-location decisions, inventory and canonicalize all key mounts accessible to the AI provider ecosystem (e.g., `/mnt/ace`, `/mnt/ace-data` symlink alias, `/mnt/local-analysis`, `/mnt/elements`, `/mnt/remote`). Second-level folder taxonomy then flows cleanly from this foundation.
