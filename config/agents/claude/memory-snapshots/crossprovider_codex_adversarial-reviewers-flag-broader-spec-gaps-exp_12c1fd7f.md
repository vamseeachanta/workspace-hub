When scope is narrowed ('cover exactly these 20 behaviors'), reviewers may initially surface out-of-scope coverage gaps. Request explicit reassessment against ONLY the enumerated items and push back on findings outside the stated scope. Clarify whether the narrowed scope is intentional or a discovery.
