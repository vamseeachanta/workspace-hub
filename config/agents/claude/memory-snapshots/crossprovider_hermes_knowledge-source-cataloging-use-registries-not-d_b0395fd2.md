For large repo ecosystems with 1M+ documents, leverage existing intelligence registries (YAML configs, JSONL indexes, pre-built reports) rather than re-scanning directories. Registry-based cataloging is maintainable; directory scans require periodic re-indexing and don't capture pre-built relationships.
