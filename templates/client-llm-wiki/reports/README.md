# Report and chatbot provenance

Use this folder for report-output manifests, not generated bulky deliverables unless intentionally small and approved.

Every client-facing HTML/PDF/chatbot pack should declare:

- input source IDs
- execution tool/code revision
- compute environment
- raw output path
- final output path
- citation/evidence manifest
- privacy classification
- publishability decision

PDFs should be limited derivatives of approved HTML/report sources, not the primary evidence store.
