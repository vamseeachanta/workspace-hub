# WRK-5140: Remove deprecated next-id.sh, enforce gh-next-id.sh

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eliminate the deprecated `next-id.sh` local counter and migrate all callers to `gh-next-id.sh`, which allocates WRK IDs from GitHub issue numbers.

**Architecture:** Replace `next-id.sh` with a hard-error stub that points callers to `gh-next-id.sh`. Update 5 live caller scripts to call `gh-next-id.sh --title <title>` directly. Add deterministic collision prevention to `gh-next-id.sh`: after getting a GH issue number, check it against all existing local WRK IDs (pending/working/done/archive). If collision detected, burn the number by closing the GH issue as "ID collision placeholder" and retry until a free number is found. Analysis shows ~40 collisions in the 1332-1392 range, then clear sailing from 1393+.

**Tech Stack:** Bash, Python, gh CLI

```bash
#!/usr/bin/env bash
# generate-reserved-ids.sh — scan all queue dirs and emit a sorted blocklist
# of every WRK ID that has ever been used locally.
# Output: one numeric ID per line, sorted, to stdout.
set -euo pipefail
WORKSPACE_ROOT="${WORKSPACE_ROOT:-$(cd "$(dirname "$0")/../.." && pwd)}"
QUEUE_DIR="${WORKSPACE_ROOT}/.claude/work-queue"

{
  # Queue directories
  for dir in pending working done blocked; do
    for f in "${QUEUE_DIR}/${dir}"/WRK-*.md 2>/dev/null; do
      [[ -f "$f" ]] || continue
      basename "$f" | grep -oE '[0-9]+'
    done
  done
  # Archive (root + monthly subdirs)
  find "${QUEUE_DIR}/archive" -name 'WRK-*.md' 2>/dev/null | while read -r f; do
    basename "$f" | grep -oE '[0-9]+'
  done
  # Assets dirs (evidence of past work, even if .md deleted)
  for d in "${QUEUE_DIR}/assets"/WRK-*/; do
    [[ -d "$d" ]] || continue
    basename "$d" | grep -oE '[0-9]+'
  done
} | sort -n -u
```

- [ ] **Step 3: Add blocklist check + auto-burn to gh-next-id.sh**

Add before `_try_github()`:

```bash
# ── Blocklist-based collision check ─────────────────────────────────────────
# Checks a static file of all historically-used WRK IDs plus live queue scan.
# This prevents GH issue numbers from colliding with any existing WRK,
# including the 5000+ machine-partitioned block.
SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
BLOCKLIST="${WORKSPACE_ROOT:-$(cd "$SCRIPT_DIR/../.." && pwd)}/config/work-queue/reserved-wrk-ids.txt"

_wrk_id_is_reserved() {
  local id_num="$1"
  local blocklist="${2:-$BLOCKLIST}"
  # Check static blocklist (fast — grep on sorted file)
  if [[ -f "$blocklist" ]] && grep -qx "$id_num" "$blocklist"; then
    return 0
  fi
  # Fallback: live scan in case blocklist is stale
  local ws_root="${WORKSPACE_ROOT:-$(cd "$SCRIPT_DIR/../.." && pwd)}"
  local queue_dir="${ws_root}/.claude/work-queue"
  for dir in pending working done blocked archive; do
    [[ -f "${queue_dir}/${dir}/WRK-${id_num}.md" ]] && return 0
  done
  for f in "${queue_dir}/archive"/*/WRK-"${id_num}".md; do
    [[ -f "$f" ]] && return 0
  done
  [[ -d "${queue_dir}/assets/WRK-${id_num}" ]] && return 0
  return 1
}
```

Then in `_try_github()`, after extracting `issue_number`, add the burn loop:

```bash
  # ── Collision avoidance: burn GH numbers that collide with existing WRK IDs ──
  local max_retries=200  # covers all 177 known collision candidates
  while _wrk_id_is_reserved "$issue_number" && (( max_retries-- > 0 )); do
    >&2 echo "gh-next-id: collision — WRK-${issue_number} exists, burning GH #${issue_number}"
    gh issue close "$issue_number" --repo "$REPO" \
      --comment "ID collision — WRK-${issue_number} already existed locally. Burned by gh-next-id.sh (WRK-5140)." \
      2>/dev/null || true
    # Create next issue
    issue_url=$(gh "${gh_args[@]}" 2>/dev/null) || return 1
    issue_number="${issue_url##*/}"
    if [[ -z "$issue_number" || ! "$issue_number" =~ ^[0-9]+$ ]]; then
      >&2 echo "gh-next-id: failed to extract issue number from: $issue_url"
      return 1
    fi
  done
  if _wrk_id_is_reserved "$issue_number"; then
    >&2 echo "gh-next-id: ERROR — still colliding after retries. Manual intervention needed."
    return 1
  fi
```

After the final successful allocation, append the new ID to the blocklist:

```bash
  # Record newly allocated ID in blocklist
  if [[ -f "$BLOCKLIST" ]]; then
    echo "$issue_number" >> "$BLOCKLIST"
  fi
```

```python
NEXT_ID_REL = Path("scripts") / "work-queue" / "gh-next-id.sh"

def _get_next_id(workspace_root: Path, title: str = "auto-captured WRK") -> str:
    """Call gh-next-id.sh to get GitHub-backed WRK ID."""
    script = workspace_root / NEXT_ID_REL
    result = subprocess.run(
        ["bash", str(script), "--title", title],
        capture_output=True,
        text=True,
        cwd=str(workspace_root),
        env={**os.environ, "WORKSPACE_ROOT": str(workspace_root)},
    )
    if result.returncode != 0:
        print(f"ERROR: gh-next-id.sh failed: {result.stderr}", file=sys.stderr)
        sys.exit(1)
    # gh-next-id.sh outputs ID on line 1, URL on line 2
    raw_id = result.stdout.strip().split("\n")[0]
    return f"WRK-{raw_id}"
```
