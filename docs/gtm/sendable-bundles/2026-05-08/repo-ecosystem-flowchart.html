Examples: wall thickness, freespan/VIV, vessel suitability
Operating promise: repeatable studies become reusable software assets; AI agents handle orchestration, tests, and review evidence; senior engineers focus on assumptions, governing checks, and client decisions.

Why this matters

  • Faster option screening before teams commit heavy engineering hours.
  • Reusable code/data/knowledge instead of one-off spreadsheets.
  • GitHub traceability for assumptions, tests, issues, and report versions.
Governance: Issue → plan → adversarial review → user approval → TDD implementation → verified closeout.
Engineering scope: subsea pipelines, rigid jumpers, vessel suitability, OrcaFlex/AQWA/ANSYS extensions.
Caveat: public artifact only; client-specific data and confidential details stay out of public repos.
