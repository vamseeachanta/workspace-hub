Consumer adapter fixture contract v1

Scope: issue 3615. This isolated prototype maps synthetic event envelopes into existing advisory workflow requests. It does not implement native hook ingress, authenticate approval, establish filesystem containment, or install enforcement.

Input and output

normalize_event(event, context) accepts raw UTF-8 JSON bytes or text. The existing receipt parser rejects duplicate keys and non-finite values and bounds input to 1 MiB, depth 64 and 100,000 nodes. Context is a bounded canonical-JSON object using existing workflow request fields.

The exact event envelope contains schema_version ("1"), provider (claude or codex), event_kind, payload, and a nonempty inert evidence_reference. Provider labels identify fixtures; they do not attest origin. References are never dereferenced.

The result contains exactly mapping_status, request, and sorted unique reason_codes. A mapped request is a detached copy. Unsupported or incomplete inputs return a null request. The harness calls the unchanged workflow_decision.assess separately only for mapped requests, retaining separate adapter_result and assessment_result records.

Binding and authority

Context shall provide the existing version, provider, edit operation, bounded repository/task/operation scope, changed paths, and effects. Event and context path sets shall agree after the existing lexical normalization. Absolute paths, drive-qualified paths and traversal fail binding. Lexical agreement does not establish real filesystem ownership: symlinks, junctions and nonexistent destinations require a future trusted ingress.

Structured edits require local-reversible effect and reject a conflicting read-only claim. Additional substantial or consequential effects are retained. A mapped request is not an authorization: the existing assessor determines advisory disposition, and caller references do not authenticate approval. Metrics and reuse references remain unverified inputs under the existing assessor contract.

Purity and evidence

The normalizer performs no file, network, subprocess or locator access and does not mutate context. Resource exhaustion beyond the parser bounds is not represented as a universal deterministic-error guarantee. Fixtures shall retain raw JSON where duplicate keys matter. Conjectural examples shall never be relabeled captured. Native evidence requires original bytes, digest, runtime version and actual event binding; a model transcript alone does not satisfy this criterion.

Duplicate-key rejection applies to the raw event only. The harness supplies parsed context and owns any prior context parsing; duplicate keys lost by a caller parser cannot be recovered here. MALFORMED_EVENT is the frozen v1 label for malformed input on either side. Python object inputs are ordinary harness data, not an isolation boundary against hostile Python classes.

Backslashes fold to forward slashes under the shared lexical normalizer. A POSIX filename containing a literal backslash can therefore alias a Windows-separated path; trusted ingress shall reject or platform-qualify that ambiguity. A nonempty unverified authorization reference moves an otherwise routine assessment from needs-context to conditional-routine; this remains conditional on independently established authority. The mapping wrapper shall retain source event digests beside results; the three-field mapping API itself is not a standalone provenance receipt.

Native deployment requires a separately verified ingress that establishes owner roots, event authenticity, full effects and approval provenance. Successful file edits during a trial do not establish hook coverage. The pure module contains no installation or settings mutation operations. Saved machine settings were not snapshotted before native trials, so preservation across those trials is not established.
