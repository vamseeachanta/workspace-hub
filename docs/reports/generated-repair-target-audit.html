Worked example

Inputs: a disposable target repository whose name contains spaces, quotes, a dollar sign and a semicolon; a foreign repository containing a sentinel and a decoy builder; missing runtime outputs; an unrelated runtime file that must remain unstaged.

Method: invoke the real checker from the foreign directory, extract its emitted Bash advice, then execute that advice in the same foreign directory. Repeat with inherited Git directory, worktree, common-directory and index bindings pointing at the caller. Compare every caller file, including Git metadata, before and after. Independently enumerate staged target paths and rerun the checker.

Answer: the declared runtime outputs are generated and staged only in the target; caller bytes remain identical; the unrelated file remains unstaged; the rebuilt target passes the checker. If target entry or rebuilding fails, the command fails before staging or readback. The expected output set follows scripts/agents/build-soul-runtime.sh: Hermes, Claude, Gemini and Agy SOUL runtimes plus both Codex runtime artifacts. No engineering constants or equations apply.

Review and limits

The plan defect check addresses inherited Git overrides, shell quoting, failed entry, producer failure and broad staging globs. Artifact inspection confirms that the change only alters printed advice and adds scoped readback; no automatic repair, approval classification, ownership rule or publication action is added. Independent reciprocal provider review remains required before merge and has not been performed for this change.

Execution assumes Bash, Git and a target that retains its identity between inspection and use. Root replacement, hostile target scripts, concurrent target edits, symlink races and unrelated staged changes require additional controls; the command grants no approval to run it. Existing approval and ownership controls remain applicable. Remaining inventory candidates will require separately bounded fixes under issue 3866.
