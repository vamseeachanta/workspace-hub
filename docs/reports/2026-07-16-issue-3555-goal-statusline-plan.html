Why the old pilot plan is being replaced

  • The repo template still uses obsolete [status_line] syntax and the version pin remains 0.123.0.
  • The planning host runs Codex 0.146.0, but its registry row does not declare Codex; fleet denominator claims are currently unreliable.
  • A machine-local unconditional YOLO wrapper exists, but the repo does not own, test, or safely scope it.
  • The user selected immediate fleet rollout, not the July ace-win-2 canary.
  • The original Claude goal/statusline convergence remains in scope rather than being silently dropped.

Execution slices

  1. Pin and prove the exact Codex version that exposes default-mode requirement input.
  2. Build a TOML-aware, key-level merger that preserves all unowned local state and rolls back atomically.
  3. Build POSIX and Windows launchers with exact trusted-root matching, recursion protection, argument-preservation tests, and safe escape.
  4. Preserve the native-goal authorization boundary and converge Claude statusline deployment.
  5. Route setup and scheduled maintenance through the same pin/config/launcher/verifier path.
  6. Reconcile the live Codex roster and extend equality evidence with version, feature, config, launcher, trusted-root, and freshness dimensions.
  7. After code review, attempt every reachable target in one rollout wave and report every host independently.

Fleet truth contract

The rollout report will enumerate the actual target set immediately before execution. Each host will finish as EQUAL, DIVERGES, MISSING-EVIDENCE, or UNREACHABLE. “Immediate rollout” means one attempted wave, not an assertion that unreachable hardware was updated. No partial set will be labeled fleet-complete.

Fail-closed decisions

  • Unsupported feature or older CLI: preserve the prior working install and fail verification.
  • Malformed config or failed semantic validation: do not replace ~/.codex/config.toml.
  • Wrapper recursion, ambiguous real binary, or prefix-collision root: run no YOLO path.
  • Missing/stale direct machine evidence: never grade the host equal.
  • Secrets, prompts, transcripts, goal text, and token values will be rejected from fleet evidence.
