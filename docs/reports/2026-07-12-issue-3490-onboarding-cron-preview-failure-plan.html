Issue #3490 · T2 · lane:codex · draft

Surface cron preview failure during new-machine dry-run

Observed defect

The onboarding dry-run will currently append || true to the cron preview. A child failure can therefore be followed by Setup complete! and process exit 0.

cron preview: exit 42
current onboarding result: exit 0 + completion banner

Proposed contract

  • Linux dry-run will invoke setup-cron.sh --dry-run.
  • A failure will remain visible, return the exact child status, and stop later steps.
  • A successful preview will continue the onboarding dry-run.
  • Default Linux apply and Windows best-effort behavior will remain unchanged.
  • Fixture tests will prevent any live crontab access.

Governance boundary

The registry, staged-blob source attestation, mutation tests, operations documentation, and generated scheduler report will move together from swallow-3490 to the resolved mode contract. The unrelated harness-update debt in issue #3479 will remain untouched.

Verification

  • Hermetic executable tests for failure, success, exact arguments, no-cron, and scheduler sentinel.
  • Adversarial mutations for reintroduced swallowing, missing dry-run, generic status replacement, and branch drift.
  • Scheduler checker and deterministic HTML parity.
  • Ruff, legal diff scan, 400/50 limits, PR checks, and T2 code review.

Gate

Implementation will remain blocked until adversarial plan review finishes and the user applies status:plan-approved. No live scheduler or process action will be authorized by this plan.
