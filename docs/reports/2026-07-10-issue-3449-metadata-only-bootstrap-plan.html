Why the plan changed

The previous cleanup contract was unsafe

Pathname cleanup

A stat-then-unlink/rmdir sequence could delete a substituted victim. The new contract performs no automatic cleanup.

Ambient Git authority

Local includes, URL rewrites, replacement refs, and ambient identity could alter supposedly pinned behavior.

Incomplete final boundary

Descriptor authority ended before commit/push and the result omitted byte/mode attestation.

Locked architecture

Five independently testable boundaries

Authorize
Exact schema-0.2 private registry row; ingestion remains disabled.
Snapshot
Replacement-free committed Git tree/blob inventory.
Render
Descriptor-relative exclusive creation; no tar or rehearsal.
Attest
Untrusted external manifest with identities, modes, sizes, SHA-256.
Finalize
Independently rebuild expected content, then commit and push a literal OID.
Failure contract

Preserve evidence; never guess what is safe to delete

No pathname cleanup

No failure path will unlink, rmdir, rename, or truncate rendered objects.

Bounded residue report

Exceptions, KeyboardInterrupt, and SystemExit will report completed members, uncertain member, stage, and clone identity.

No ambiguous retry

A partially rendered clone requires manual disposition; the renderer will not retry into it.

Git authority

Configuration, identity, credentials, and objects are explicit

ConcernRequired controlVerification
ConfigGIT_CONFIG=/dev/null, system/global disabled, caller Git variables droppedMalicious local/global controls cannot affect behavior
Clone configPass held .git/config fd into child; parse via /proc/self/fd and --no-includesReject includes, rewrites, duplicates, corrupt HEAD
ObjectsGIT_NO_REPLACE_OBJECTS=1; exact committed tree/blob IDsActive replacement ref and dirty worktree are ignored
AuthorRequire CLIENT_WIKI_GIT_AUTHOR_NAME and ..._EMAILAmbient Git config cannot supply identity
CredentialsFixed command-scoped gh auth git-credentialUnavailable credentials fail before registry mutation
Recovery state machine

Only three states permit progress

Observed statePermitted action
Symbolic unborn HEAD + independently reconstructed exact renderStage expected files, commit, retain OID, push literal OID, re-attest
Exact parentless local root commit + remote absentRetain and push its literal OID, then re-attest
Exact expected local commit + equal remote mainReturn idempotent success after re-attestation
Any identity, origin, index, worktree, commit, or SHA mismatchFail without mutation; preserve and report residue
TDD sequence

  1. Close schema downgrade, boolean, and protected-root ordering gaps.
  2. Centralize isolated Git execution and held config parsing.
  3. Replace archive rendering with exact committed blob snapshots.
  4. Remove cleanup authority and prove structured residue preservation.
  5. Persist and validate the complete external render manifest.
  6. Add descriptor-bound finalizer and three-state recovery.
