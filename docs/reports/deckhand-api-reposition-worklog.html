Deckhand — the API for real-world work

Session work review — 2026-06-28 · repositioning every public surface around the API call as the atomic unit of work. Public read tier: vamseeachanta.github.io/deckhand-sandbox/api/.

One-line finding. The mental model flips from chat-message-centric ("drive engineering work from a chat message") to API-centric: every workflow is an API path, and calling it returns a single standards-traceable HTML report URL. Chat becomes one client of the API, not the headline. The word "AI" is dropped as a descriptor — the product is deterministic computation built on real code plus industry codes & standards, not a model.

The unifying contract

Every surface points at one contract. A workflow is addressed as a path; one call returns a report URL you can open, cite, and audit.

POST /api/run
  { ref, domain, subdomain, inputs }
    → { status, report_url, artifacts, coordinate, duration_s }

report_url resolves to a self-contained HTML report whose every standards-derived value is traceable to the code clause or industry standard it came from. The same call is reachable from a chat client, a script, or a browser — the interface is the API, and chat is just one caller.

Why API-first

  • Addressable. Each workflow has a stable path (domain / subdomain / workflow). The catalog of paths is the product surface.
  • Composable. A call returns structured artifacts plus a report URL, so calls chain into pipelines without a human in the loop.
  • Deterministic. Same inputs → same result. No stochastic answer; the output is computed from real code and published codes & standards (e.g. DNV-traceable mooring / pipeline screens).
  • Auditable. The report URL is the receipt — a reviewer opens it and checks every value against its cited basis.

Determinism & honesty posture

Claims stay tied to what is runnable. The public narrative leads with the one domain that is live, deterministic, and standards-traceable (offshore), and frames every other domain as trajectory — an API path the catalog already names but has not yet shipped. "AI" is intentionally dropped as a descriptor: a caller does not buy a model, they call a path and get a report computed from real code and published industry standards. Determinism is the feature — the same inputs return the same audited report URL every time, which is what makes the output defensible to a reviewer or regulator.
