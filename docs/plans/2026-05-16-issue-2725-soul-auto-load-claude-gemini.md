### Gemini CLI `@import` mechanism (verified 2026-05-16T20:35Z via WebFetch)

Per official Gemini CLI documentation:
- **`gemini-md.html`**: "You can break down large `GEMINI.md` files into smaller, more manageable components by importing content from other files using the `@file.md` syntax. This feature supports both relative and absolute paths."

**Implication**: Phase 2 is NOT research-first — Gemini supports the same `@file.md` mechanism as Claude Code. The plan's r1 3-branch (2a/2b/2c) is collapsed into a single approach mirroring Phase 1.
