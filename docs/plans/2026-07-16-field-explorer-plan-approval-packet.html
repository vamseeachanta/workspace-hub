Fixed architecture decisions

  • worldenergydata remains authoritative for data, IDs, schemas, provenance, and licenses.
  • The website will consume only one exact HF revision through raw resolve URLs at build time.
  • The browser will use local validated assets; there will be no runtime HF dependency.
  • Markup will live in real HTML page and child-panel partials.
  • Static parent, field, and well routes will provide useful no-JS navigation.
  • One protected state ref will use a one-parent non-force push as the remote CAS; stale concurrent writers will fail.
  • Prior event hashes will remain an exact prefix and evidence paths will be content-addressed and create-only.
  • Receipts will be checked against live trusted CI, Hugging Face, and deployment provenance rather than trusted as self-authored JSON.
  • Failed candidates will preserve or restore the last-good complete site and revision cache; unproven rollback will block further promotion.
