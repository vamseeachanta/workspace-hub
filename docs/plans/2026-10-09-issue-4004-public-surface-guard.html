Issue 4004 Public Surface Guard Plan

Issue 4004 will add a reusable public-repository guard for pull-request added lines.

Scope

The change will add scripts/enforcement/check-public-surface.py, a reusable GitHub Actions workflow, tests, and a one-line adoption snippet. The blocking mode will fail on newly added host IPs, denylisted physical hostnames, secret-shaped strings, and private keys. The identifier mode will remain warn-only and will prepare one masked PR comment when a provisioned client-codename registry contains matches.

Controls

The scanner will read only added diff lines. Documentation IP ranges and explicit allowlist entries will be excluded from blocking results. Findings will report file:line, match class, and masked value. The identifier job will not echo full identifiers and will not fail the build.

Verification

Tests will cover each blocking class, allowlist behavior, masking, diff-only behavior, and warn-only identifier comment generation. CI wiring will call the same script entry point used by the tests.

Review

An adversarial implementation review will be run before closeout. O13 recorded by the PM will be noted in the draft PR body for owner confirmation at merge.
