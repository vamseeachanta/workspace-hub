Decision

No-go: do not register this machine by sharing a colleague's separate individual account, password, session cookie, OAuth token, or personal API key. Anthropic documents Remote Control as requiring the same account and organization used by terminal Claude Code, and its Consumer Terms prohibit sharing account credentials.

No current supported Anthropic feature provides cross-account cloud-to-local dispatch into this Windows machine. Remote Control is same-account only and rejects service-account/WIF authentication; Cloud Routines and ordinary GitHub-hosted Actions do not dispatch into local state; Desktop schedules require the app to be open and the machine awake.

Recommended: if local-machine access is essential, build a small isolated API/Agent SDK runner. Each human will retain an individual identity; the runner will use a dedicated workspace-scoped non-human service account with Workload Identity Federation. It will run under a low-privilege Windows account with an authenticated queue, worktree isolation, bounded concurrency, structured logs, workspace spending limits, and explicit machine wake handling. It will not use Remote Control. If local access is unnecessary, use Cloud Routines or GitHub Actions instead.

Ranked options

  1. Cloud Routines or GitHub Actions: preferred when a fresh repository clone and cloud/CI tools are sufficient.
  2. Isolated local API/Agent SDK runner: preferred only when jobs require this machine's local-only state.
  3. Same-account Remote Control: supported for the legitimate holder of the same account and organization, but it does not satisfy the separate-colleague-account requirement.
  4. Shared human credentials: rejected.

Key evidence

  • Remote Control runs Claude Code locally and exposes local files and tools through web/mobile, but requires subscription OAuth and the same account and organization.
  • Desktop scheduled tasks can access local state only while Desktop is open and the computer is awake.
  • Cloud Routines support schedules, API triggers, and GitHub events but run on Anthropic-managed infrastructure and are not shared between individual accounts.
  • Workload Identity Federation provides non-human service accounts and short-lived workspace-scoped automation credentials.
  • Console workspaces provide the supported boundary for scoped credentials, limits, and spending controls.
  • Consumer Terms prohibit sharing account login information, API keys, or account credentials.
