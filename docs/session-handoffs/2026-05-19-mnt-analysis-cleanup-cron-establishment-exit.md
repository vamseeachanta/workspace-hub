## Gotchas captured for future-me

1. **Hermes session-grep discriminator**: don't treat every grep hit in `~/.hermes/sessions/` as active use; discriminator is session_id ∩ running pgrep workers. The cleanup skill §6 needs this refinement.
2. **Allowlist + empty/stale handling**: `.pnpm-store/` and `.Trash-1000/` got "leave alone" verdicts based on skill allowlist, but their empty/stale state made them disposable. A future skill iteration should add an "empty-or-stale system entry" sub-class.
3. **Skill audit needs session-delta scope**: the pre-completion-cleanup-audit treated all dirty files as session-introduced when most were pre-existing concurrent-job state. A `git stash create` at session-start + diff at completion would scope correctly.
4. **Hermes cron script-path traversal guard**: scripts under `~/.hermes/scripts/` cannot be symlinks. Use a thin wrapper (3-line `exec` to the canonical) instead — the wrapper itself goes in `~/.hermes/scripts/`, canonical lives in the repo.
5. **Auto-sync push-rejection during concurrent work**: workspace-hub origin auto-advances multiple times per session from parallel Hermes auto-syncs. Rebase + autostash + `git checkout HEAD --` of conflicted harness-state files is the standard recovery; expect to do this 2-3 times per long session until the auto-sync schedule changes.
