Proposed design requirements

The shared engine will separate exit readiness, integration state and residue classification. Repository identity will use the resolved Git common directory; per-worktree identity and session ownership will remain separate. Probe errors will remain unknown. Detached and unborn HEAD, shared stashes, dirty foreign work, offline remotes, squash merges, stale receipts and concurrent updates will receive explicit treatment.

End hooks will perform no network access, dependency installation, staging, commits, pushes, deletion or PM messaging. Runtime receipts will remain private, atomic and session-scoped. Public summaries will use allowlisted fields without private repository identifiers, filenames or transcripts. Windows helpers will launch hidden and capture logs.

Installation will require empirical verification by machine, provider, client/mode, version, trust state and repository/worktree. Unsupported or offline combinations will remain uncovered. Existing hooks will be reconciled rather than duplicated; unrelated settings will be preserved.
