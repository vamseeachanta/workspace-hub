# Deckhand retirement lessons

- **Source:** [Deckhand retirement lessons](https://github.com/vamseeachanta/deckhand/blob/2ae503d5bc150faef3d16a77b2ed5ced124ea48a/docs/deckhand/LESSONS.md) (private repository; access required)
- **Captured:** 2026-10-18

Deckhand's retirement lessons preserve reusable guidance for future bots: enforce repository permissions below the model, separate authorization from message delivery and knowledge routing, isolate memory and tools, verify deployed changes, and record artifact delivery outcomes. Supporting decisions, patches and incident fixes are retained alongside the lessons page. Future implementations should use repeatable onboarding, explicit approval for privileged actions, and evaluations tied to confirmed exchanges and deployed revisions.
