## Findings

1. **The plan reinvents an existing, more precise enforcement mechanism it never cites.** `tests/helpers/stale_reference_docs.py:CORE_BANNED_STALE_REFERENCE_PATTERNS` already bans `\.claude/work-queue/`, `\.claude/skills/workspace-hub/work-queue-workflow/SKILL\.md`, and `\.claude/skills/workspace-hub/workflow-gatepass/SKILL\.md` — exactly the strings this plan targets. `tests/docs/test_banned_stale_references.py` runs them over `STRICT_FILES`. The plan instead proposes a brand-new `tests/docs/test_provider_entrypoint_surfaces.py` with ad-hoc, weaker patterns (`docs/work-queue-workflow.md`, `.claude/work-queue/`, `WRK-*`). The correct, lower-risk implementation is to enroll `.gemini/GEMINI.md` and `.codex/CODEX.md` into the existing `STRICT_FILES` and reuse `scan_stale_reference_hits`. The plan is unaware of this extension point. (MAJOR — duplicate/divergent enforcement.)

2. **The actual enforcement gap is enrollment, and the plan's test patterns do not close it.** `.gemini/GEMINI.md:6` (`.claude/work-queue/`) and `.gemini/GEMINI.md:9` (`work-queue-workflow/SKILL.md` + `workflow-gatepass/SKILL.md`) hit three existing banned patterns, but `.gemini/GEMINI.md` is **not** in `STRICT_FILES`. Meanwhile the plan's proposed patterns do **not** match line 9 at all: `work-queue-workflow/SKILL.md` contains no `work-queue-workflow.md`, no `.claude/work-queue/`, and no `WRK-`. So the plan's new test would pass while leaving the dangling deleted-skill references (the skills are confirmed **MISSING** on disk) intact in `.gemini/GEMINI.md`. The test does not enforce the plan's own stated gap (line 53). (MAJOR.)

3. **Evidence integrity: the plan's reproduced grep output (lines 122-128) is not faithful to its documented command.** Re-running the identical command shows the plan (a) lists `.gemini/GEMINI.md:9` as a match — it is **not** matched by the stated regex; and (b) omits three real matches: `.codex/CODEX.md:6` (`WRK-* mapping`), `config/agents/codex/SOUL.delta.md:40` (`WRK-scoped work`), and `config/agents/codex/SOUL.delta.md:61` (`work-queue-workflow/SKILL.md`). A gap-proof that misstates its own command output undermines the Resource Intel section. (MAJOR.)

4. **New `AGENT_SESSION_COORDINATION_PROTOCOL.md` is unscoped scope-creep and inverts the #684 canonicality decision.** #2421 is provider-entrypoint *normalization*; llm-wiki #684's follow-up is a "provider-*pointer*" task (point `AGENTS.md`/`GEMINI.md` at the existing ASCP). The plan instead authors a net-new workspace-hub governance standard (acceptance: "claim-before-work, TTL/renewal, release/handoff expectations") whose actual content is entirely undefined — the plan specifies only that the file "exists and defines" these. A plan cannot be TDD-implemented against an undefined standard, and the Risk note ("create a workspace-hub standard as the canonical control-plane anchor and can later allow llm-wiki to point back to it") unilaterally relocates canonicality away from where #684 placed it. (MAJOR — scope + undefined deliverable.)

5. **`test_concurrent_session_standard_is_discoverable` structurally conflicts with `test_agent_harness_files_stay_within_line_budget`.** `AGENTS.md` is at exactly 20 lines (the cap; `wc -l` = 20). The discoverability test (pseudocode line 190) requires `AGENTS.md` to reference `AGENT_SESSION_COORDINATION_PROTOCOL.md`; the budget test asserts ≤20. Adding the anchor requires deleting an existing canonical line (every current line is a load-bearing gate/policy). The plan's mitigation ("replace stale lines whenever possible") is empty here: grep confirms `AGENTS.md` has **no** stale/work-queue line to swap. Which canonical line gets sacrificed is unspecified. (MAJOR.)

6. **The blanket `WRK-*` assertion over `config/agents/codex/SOUL.delta.md` sweeps in operational, non-deprecated content.** Line 40 — "Codex review iteration cap: 3 per WRK/non-WRK plan; `submit-to-codex.sh` enforces via `review-iteration.yaml` for WRK-scoped work" — matches `WRK-` but describes the live review-iteration-cap mechanism, not a deprecated workflow gate.
