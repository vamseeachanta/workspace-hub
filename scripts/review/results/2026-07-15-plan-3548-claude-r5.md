`★ Insight ─────────────────────────────────────`
**The empty-ruleset trap.** Gitleaks' `--config` *replaces* the default ruleset rather than extending it. A TOML with only an `[allowlist]` block and no `[[rules]]` (and no `[extend] useDefault = true`) is a syntactically valid config with **zero detection rules** — gitleaks loads it, logs nothing alarming, and reports "no leaks found" on anything. This is the same failure shape as `.claude/rules/verify-ci-lint-toolchain.md` §4 (absent binary "passes" silently), but nastier: the binary is present, the config parses, the exit code is 0. Only a **positive control** — feeding the scanner a secret it must catch — distinguishes a clean tree from a dead scanner.
