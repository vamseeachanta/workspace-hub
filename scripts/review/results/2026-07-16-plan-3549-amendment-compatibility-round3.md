## Blocking findings

1. **The native-Windows fallback test can still prove only wrapper exit propagation, not the real CLI's Windows exit-4 boundary.** The focused addendum says every PowerShell wrapper test will capture delegation through a fake `uv.cmd`, then says the Tailscale wrapper will append `--fallback` and prove exit 4 before fake `ssh.cmd` runs (`docs/plans/2026-07-16-issue-3549-amendment.md:81-94`). The base plan repeats argv capture through a `.cmd` shim and an exit-4 assertion (`docs/plans/2026-07-16-issue-3549-registry-connection-helpers.md:241-251`). A fake `uv.cmd` can return 4 without executing `connect-workstation.py`; that passes both assertions even if the actual native CLI attempts overlay access, maps the error incorrectly, or launches SSH. The current implementation makes the OS decision inside Python (`src/workspace_hub/workstations/connection.py:329-339`), so wrapper-only propagation is not evidence of that boundary. **Required change:** specify two distinct native nodes: (a) fake-`uv.cmd` tests for each exact wrapper-to-CLI argv vector, and (b) a Tailscale-wrapper integration using the real installed `uv`/Python CLI on Windows, with only SSH faked, asserting exit 4, the stable `unsupported_platform` diagnostic, and zero SSH invocations. Required-native mode must run both without skip.

2. **The correction matrix omits four of the explicitly required long-option negative controls.** Round 1 required sanitized exit 2 without resolution or launch for every long-option prefix: `--fall`, `--dry`, `--reg`, `--over`, and `--use` (`scripts/review/results/2026-07-16-plan-3549-amendment-compatibility-round1.md`, Finding 6). The final addendum specifies only `--fall` and asserts only that row is rejected (`docs/plans/2026-07-16-issue-3549-amendment.md:40-57`); `--dry`, `--reg`, `--over`, and `--use` appear nowhere in either executable plan. `allow_abbrev=False` is the intended implementation, but a single representative test does not preserve every public option against later per-option parsing drift and does not satisfy the requested negative-control matrix. **Required change:** parameterize all five prefixes, require exact redacted usage exit 2, and assert registry resolution plus child launch are both untouched for every row.
