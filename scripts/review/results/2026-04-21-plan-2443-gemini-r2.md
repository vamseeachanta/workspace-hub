### Verdict: MINOR

### Summary
The revised plan effectively addresses the Wave 1 MAJOR findings. The lychee escape hatch is rigorously gated (preventing whole-host exclusions), the 20-rule lint floor guarantees a meaningful CI check, TDD practices are properly integrated, and the deferred items are legitimately justified. However, there are two minor execution flaws regarding a missing workflow path in a PR trigger and an unmet standard library dependency in the TDD test script.

### Issues Found
- In `markdown-lint.yml`, the `pull_request` trigger's `paths` array omits `.github/workflows/markdown-lint.yml` (unlike its `push` trigger counterpart and the `link-check.yml` PR trigger). A PR that modifies only this workflow file will fail to trigger the action, preventing automated validation of the workflow changes.
- The TDD Step 2 assertion script relies on `import json5`, which is not a part of the Python standard library. Executing this command in a standard environment will result in a `ModuleNotFoundError` rather than successfully validating the floor rules, causing a false negative in the TDD sequence.

### Suggestions
- Add `'.github/workflows/markdown-lint.yml'` to the `pull_request` -> `paths` array in the `markdown-lint.yml` workflow definitions.
- For the TDD Step 2 script, either explicitly note a prerequisite to `pip install json5`, rewrite the check using standard CLI tools (like `jq` or `grep`), or rename the configuration to `.markdownlint.json` (no comments) to permit the use of Python's built-in `json` module.
