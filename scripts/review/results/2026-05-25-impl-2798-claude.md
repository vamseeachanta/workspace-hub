# Adversarial implementation review — #2798 (Claude)

**Reviewer:** Claude (worktree, code-stage) · **Date:** 2026-05-25 · **Branch:** feat/2798-completeness-gate

## VERDICT: MAJOR

Core logic + tests are sound (24 green), but the GitHub Action's *scope* has a MAJOR defect and there are two MINORs. Not merge-ready as-is.

## MAJOR

1. **The Action reopens EVERY closed issue lacking a record — including no-work closes.** `completeness-gate.yml` fires on all `issues.closed` with no exemption. The rule says "do NOT apply when the issue produced no work (duplicate/won't-fix/invalid)", but the workflow has no such skip — it would reopen routine duplicate/won't-fix closes, which is disruptive and wrong. **Fix:** gate the job on `github.event.issue.state_reason == 'completed'` (skips `not_planned` closes) AND only enforce for issues that reached implementation (e.g., carried `status:plan-approved`). Without this the gate is too aggressive to ship.

## MINOR

2. **Gate-check trusts the stamped record without binding it to the closing commit.** `evaluate_close` validates pct≥threshold but not that the record was computed at the merged state. A stale record (pct=95 from an old commit) stamped on the body would pass. `completeness_score` fails-closed on stale *matrix snapshot*, but the *gate* doesn't re-validate freshness. Mitigation: carry the PR/commit SHA in the record and have the runner compare to the issue's merged-PR head; or recompute in the Action.

3. **Unset `vars.COMPLETENESS_OWNERS` ⇒ every close blocked.** Empty owners set means no `label_actor` is ever authorized → all closes reopened. This is fail-closed (safe) but a silent foot-gun. **Fix:** document the repo-variable as a hard prerequisite, and have the Action emit a clear "owners var unset" message rather than a generic deny.

## NITS
- `_RECORD_RE` (`\{.*?\}`) is non-greedy and breaks if an evidence string contains `}` — fails closed (record=None→deny), acceptable but fragile; consider a fenced-block parser.
- `classify()` prefix-match: package-map keys should be trailing-slash to avoid `src/digitalmodelX/` matching `src/digitalmodel`. Document the map convention.
- `round()` is banker's rounding; immaterial for integer quality_scores but note it.

## Recommendation
Fix MAJOR #1 before merge (the Action scope). MINOR #2/#3 should be addressed or filed as fast-follows. Logic/tests otherwise solid.
