## Findings

### F1 (MAJOR → fixed inline): migration transition was hand-waved
Original draft said stale placeholder evidence would be "treated identically to today for at most one weekly cycle; accept the one-cycle misgrade." That is a silent mis-grade window of exactly the kind this issue exists to eliminate. **Fix applied:** deterministic `schema_version` 4→5 gate — builder treats scheduler fields in schema<5 `os: windows` evidence as `unknown` (MISSING-EVIDENCE); Linux legacy evidence keeps measured values. Two TDD rows added covering both sides of the gate.

### F2 (MINOR → fixed inline): Windows `job_count` semantics unstated
`schtasks` enumerates all system tasks, so Windows `job_count` will be noisy (~200+) and incomparable with Linux crontab counts. Plan now states job_count is display-only (it is never voted or graded — verified `extract_value()` scheduler mapping uses only the two booleans) and the probe matches task names only, preserving the C4 serialization allowlist.

### F3 (MINOR, open — owner decision, correctly flagged): ace-win-2 hermes contradiction
`providers.hermes: present` vs `hermes_home: absent` on the same box means one probe is wrong or hermes is half-installed. The plan cannot pick the baseline value; it correctly routes this to the owner at approval. Reviewer note: whichever value is chosen, the false probe should be identified during implementation (cheap: compare what each probe actually tests) — recommend adding that as an implementation sub-step rather than leaving both probes unexamined.

### F4 (MINOR, open): render-layer verdict coverage asserted but not proven
The plan assumes existing CSS/legend classes cover CONFORMS/BELOW-BASELINE/MISSING-BASELINE on rows that previously emitted EQUAL/DIVERGES. Legend text suggests classes are keyed by verdict string, not dim, but this is unverified until implementation. Covered implicitly by the acceptance criterion requiring a live rebuild; recommend the implementer eyeball the rendered group-row aggregation (worst-of) for the three reclassified dims.
