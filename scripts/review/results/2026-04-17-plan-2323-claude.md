## Findings
- **Correctness — pseudocode prompt invocation will not work for Codex or Gemini.** Line 87: `codex: codex exec --no-interactive "$(cat $prompt_file) $plan_file"` — this passes the *filename as text*, not the file's content. Codex needs the plan content inlined (verified empirically in this very session — Codex initially tried GitHub MCP lookup instead of reading the path, returning false MAJOR). The pseudocode retains the broken pattern.
- **Correctness — Gemini filesystem sandbox also blocks path-based prompts.** Direct evidence: `gemini -p "... $plan_file"` returned `Path not in workspace: Attempted path "/mnt/local-analysis/workspace-hub/..." resolves outside the allowed workspace directories`. Plan's pseudocode uses the broken pattern. Verified live during initial review wave.
- **Correctness — `scripts/review/plan-review-prompt.md` acceptance check is circular.** AC "regression test asserts their presence verbatim" — passes if the prompt file literally contains the text. It does not verify the prompt *works* on any provider. The self-test AC addresses this but only against a deliberately-weak fixture, which is a trivially non-APPROVE case.
- **Correctness — self-test AC is quota-expensive and CI-hostile.** "Provider outputs for the wrapper's own self-test must include at least one non-APPROVE verdict" requires a live run of all three providers on every CI pass. No offline / mock path specified. Quota burn per CI run is substantial.
- **Correctness — verdict-parsing depends on providers always emitting `## Verdict` heading.** v2 prompt strongly specifies headings, but no test covers a provider that returns the verdict under a different heading or with preamble. Disagreement report parser will fail silently.
- **Scope — retry/overwrite behavior unspecified.** `Files to Change` creates per-invocation artifacts at `scripts/review/results/YYYY-MM-DD-plan-NNN-<agent>.md`. On re-run same day, does it overwrite (loses prior review) or append (corrupts parsing) or suffix? Plan silent.
- **Scope — cost guard is a comment, not code.** `Risks` says "document cost in the script header; do not auto-fire on cron by default" — this is prose, not a script-level guard. Should be a `--force` requirement when a same-day artifact already exists.
- **Scope — Gemini #1326 (NO_OUTPUT) unresolved.** Plan tolerates via `UNAVAILABLE` verdict, but that means plans will frequently land with 2-provider coverage (Claude + Codex), which the `cross-review-policy` skill says is a reduction requiring documented reason per invocation. Plan doesn't emit that documentation automatically.
- **Scope — no E2E test with real providers.** The self-test AC is synthetic-fixture-only. No "end-to-end dry run against a real plan" step before shipping.
