## Findings

### MINOR-1: API RP 39 ambiguity — not the right standard

**Evidence:** Plan §"Public-safety boundary" and §"Files to change" references "API RP 39" as the stimulation-chemicals standard.

- **API RP 39** — actual title is "Recommended Practices on Measuring the Viscous Properties of a Crosslinked Water-Based Fracturing Fluid" (real, but narrow scope — frac-fluid viscosity testing, not stimulation chemicals broadly).
- **The user likely meant** API RP 42 (Recommended Practices for Laboratory Testing of Surface Active Agents for Well Stimulation), or API RP 13 series (mud testing applies adjacent to frac-fluid rheology).

**Why this matters:** The standards-anchor page would have wrong scope coverage.

**Recommendation:** Replace "API RP 39" with the specific standards needed:
- For frac-fluid rheology: API RP 39 IS appropriate but narrow — name it explicitly as "frac-fluid viscosity testing"
- For frac-fluid chemistry broadly: cite SPE Monograph 17 (Reservoir Stimulation, 3rd Ed., Economides & Nolte) as license-clear authoritative reference
- For surfactant testing: API RP 42

### MINOR-2: DFIT abbreviation introduced without explanation in plan body

**Evidence:** Plan §"Sub-issue 3" mentions "DFIT analysis" without expansion. Reviewers (especially adversarial ones) flag undefined acronyms.

**Recommendation:** Expand on first use: "Diagnostic Fracture Injection Test (DFIT)". Concept page itself should also define on first use.

**Evidence:** Plan §"Sub-issue 3 — Refrac decisioning" lists one concept page (`refrac.md`). Acceptance is just "concept page lands." That's a thin sub-issue compared to hydraulic-fracturing (5+ topic clusters in one page).

**Why this matters:** Phase 1 pattern was balanced sub-issues (each closing ≥1 standard + ≥1 concept). Refrac sub-issue under-delivers vs that pattern.

**Recommendation:** Either (a) fold refrac into hydraulic-fracturing as a section (reduces sub-issue count to 2), or (b) expand refrac sub-issue scope to also include DFIT methodology page + production-history-analysis decision page. Lean toward (b) — refrac decisioning IS a distinct skill set from initial frac design.
