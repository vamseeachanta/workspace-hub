### Suggestions
- Replace the fixed `39` assertion with a dynamic before/after `<loc>` count comparison captured from the implementation commit, and move `39` to non-normative background context if you want it recorded.
- Add an explicit metadata-preservation check: parse sitemap entries before/after and assert that only the host prefix changed while each row's associated `lastmod`, `changefreq`, and `priority` values stayed identical.
- Add a preflight step for `xmllint` availability, or document an approved fallback validator so implementation does not stop on an avoidable tooling gap.
