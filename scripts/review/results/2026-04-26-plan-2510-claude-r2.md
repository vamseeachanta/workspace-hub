4. **GDSII binary-timestamp determinism trap is hand-waved, not solved.** §Determinism Contract line 245 says "If tool-generated GDS contains unavoidable non-deterministic bytes, tests must verify deterministic metadata/read-back invariants and the report must state which binary fields are tool-controlled; otherwise repeated GDS bytes should match." GDSII spec embeds modification/access timestamps in BGNLIB and BGNSTR records, and gdsfactory writes wall-clock by default. The plan does not direct implementation to pin them (e.g., the `timestamp=` kwarg or equivalent) — without that, the manifest hash for `chip_package_demo.gds` drifts run-to-run and `test_outputs_are_deterministic_across_runs` (line 197) fails. The plan should either (a) prescribe explicit timestamp pinning, or (b) exclude the `.gds` from the deterministic-bytes manifest check, but it currently does neither cleanly.

5. **§Determinism Contract contradicts §TDD line 197 wording.** §Determinism Contract line 242 says "Do not serialize wall-clock timestamps into checked-in metadata, SVG, CSV, GDS read-back JSON, or manifest-covered files." But §TDD line 197 still reads "repeat runs produce identical manifest hashes excluding regeneration timestamp policy". If no timestamps are serialized, the "excluding … timestamp policy" qualifier is dead text. If they are (in the .gds binary per Finding 4), then the contract is violated. One of the two must be edited to match the other.

6. **GDS round-trip comparison shape is unspecified.** §Pseudocode line 159 says "compare read-back invariants against generated geometry metadata", and §TDD line 195 says "matching invariants". gdsfactory's `import_gds` may snap polygons to grid, merge co-located rectangles, reorder by GDSII layer/datatype tuple, and lose port labels (port labels round-trip is lossy in vanilla GDS). The plan does not state: (a) which fields are compared (layer count, polygon count, bbox, area, label set?), (b) what tolerance applies for floating-point bbox comparison (µm? nm?), (c) how layer identity is keyed (name vs `(layer, datatype)`). As written, the round-trip test could silently pass with semantically broken round-trip.
