This is also a regression vs. codex-r6 finding #6 (which flagged the upper bound `≤ 4×`); the patch swung the test from a justified upper bound to "exact", which is *more* restrictive, not less.

5. **Manifest-relative-to-parent rule has no CLI guard against `--report` outside `--output`.** Plan §line 270 (Acceptance Criteria) and §line 337 (Determinism Contract) both require manifest entries to be relative to the manifest file parent, validated by `cd data/semiconductor/layout_cad_demo && sha256sum -c artifact_manifest.sha256`. A user passing `--report ../../docs/reports/foo.md` silently breaks the manifest contract. Either constrain the CLI or compute relative paths in a way that doesn't require co-location.
