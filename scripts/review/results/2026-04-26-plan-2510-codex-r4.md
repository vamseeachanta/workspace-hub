Plan §Determinism Contract requires the implementation to “pin GDSII BGNLIB/BGNSTR timestamps to a fixed UTC tuple using the GDSFactory/kfactory writer API available in `gdsfactory==9.40.2`.” The verified API surface does not support a fixed UTC tuple in the cited layer: GDSFactory `Component.write_gds` delegates to KLayout `SaveLayoutOptions`, KLayout exposes `gds2_write_timestamps` as a boolean that writes current time if true and zeroes timestamp fields if false, and kfactory’s default `save_layout_options()` already sets `gds2_write_timestamps = False`.
