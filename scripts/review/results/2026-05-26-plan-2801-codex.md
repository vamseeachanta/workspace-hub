## MAJOR
- **C1 — Majority ties undefined.** `EQUAL if value==majority else DIVERGES` with `Counter.most_common(1)`: 2 reporters disagreeing, or 4 split 2/2, has no strict majority → input-order picks one EQUAL, other DIVERGES (false green). No tie test in TDD list.
- **C2 — Windows collector branch unreliable.** `wmic` is not reliably present on modern Windows; `MINGW*/MSYS*` uname branches need explicit handling. Acceptance still requires Windows equality reports → can break collection / emit inconsistent schema on licensed-win-*.
- **C3 — TDD does not cover the verdict state machine.** Missing: 2-equal→EQUAL, 2-disagree→tie, 4-split-2/2, expected-diff vs missing/unreachable precedence, unreachable-with-stale-report, malformed/deferred payloads.
- **C4 — No redaction/schema-allowlist for git-tracked machine state.** Collector serializes provider presence, gh_auth, scheduler signals, dispatch names, repo paths, GPU, cron-derived names into a git-tracked (and potentially public) file. No invariant that cron LINES / env values / tokens / absolute home paths are never serialized.

## MINOR

- **C6 — compute whole-object EXPECTED-DIFF can hide collection failures.** Distinguish expected hardware variance from missing/parse-error values inside compute.
