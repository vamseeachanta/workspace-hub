4. **Completeness gate:** the issue lacks `gate:completeness`; the cited score module is not a CLI; changed-file classification, path map, evidence manifest/weights, persistence, and HTML mechanics are absent.
5. **Review evidence:** canonical provider files are unavailable/stale. Revision-stamped usable reviews and a final resolution record are required before status advancement.
6. **County cluster contract:** cluster cardinality is undefined, so a single county could pass. Every candidate needs the same fixed cardinality and county-specific evidence rule.
