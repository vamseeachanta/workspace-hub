## Findings

### A — MINOR — allowlist in prose, not tested
**Defect:** "server must not expose .env or secrets/" was documentation-only. Red-team test absent.
**Fix applied:** `allowlist.py` module + `test_allowlist_blocks_env` + `test_allowlist_blocks_secrets`.

### B — MINOR — hard-dep on embeddings index
**Defect:** original plan made `wiki_search` non-functional until #2393 shipped. Blocked incremental delivery.
**Fix applied:** fallback grep path when embeddings index not built; tested.

### C — MINOR — "read-only by design" invariant not enforced
**Defect:** nothing prevented a future contributor adding a write tool. Invariant needed programmatic check.
**Fix applied:** `test_read_only_no_writes` — static scan of tool registry asserts zero write methods.

### D — MINOR — p95 latency in issue body, no AC test
**Defect:** issue body promises <500ms p95 for `doc_key_lookup` but plan had no perf test.
**Fix applied:** `test_perf_doc_key_lookup_p95` — 100-call benchmark asserts threshold.

### E — MINOR — CFR tool created hard dep on #2395
**Defect:** MCP server couldn't ship until CFR ingestion complete.
**Fix applied:** stub mode — `test_cfr_lookup_stubs_if_no_registry` returns "feature-not-available" gracefully.

### F — NOTED — Codex stdio support
**Observation:** Codex sandbox access to stdio MCP is unverified. HTTP bridge via Hermes exists but adds latency. If Codex adds native stdio MCP later, adapter deferred.
**Action:** accepted; documented in Risks.

### G — NOTED — query log retention
**Observation:** JSONL audit log grows without bound absent retention policy.
**Action:** daily rotation + weekly compress cron — called out in plan; not a defect but worth monitoring.

### H — verified — no operating-model violations
No layer invention, no circular flows, `doc_key` remains canonical identity. Server surfaces tier semantics in responses per §7 rather than violating them.
