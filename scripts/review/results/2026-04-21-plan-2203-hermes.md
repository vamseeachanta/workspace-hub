## Findings

1. MAJOR — The draft assumes `.git/hooks/pre-push` is a safe install target in linked worktrees.
   - Evidence: linked worktrees use `.git` as a file and the real hook location is under the common git dir, not a per-worktree `.git/hooks/` directory.
   - Impact: a plan centered on copying to `REPO_ROOT/.git/hooks/pre-push` does not actually solve worktree-hook installation.

2. MAJOR — The draft under-specifies preservation of the current pre-push gate chain.
   - Evidence: `scripts/enforcement/install-hooks.sh` currently wires enforcement-env, review gate, stage-prompt drift, state-file-size, and cadence-sync into pre-push.
   - Impact: replacing the hook without an explicit composition contract risks silently dropping existing enforcement behavior.

3. MAJOR — The draft’s new-branch classification logic is not defined for the zero-remote first-push case.
   - Evidence: live hook sets `RUN_ALL=true` specifically because `remote_oid == ZERO`; the plan used vague “compare range” language without defining the comparison base.
   - Impact: implementation could under-check real pushes or fail to solve the landing blocker.

4. MINOR — The draft overstated the current test baseline.
   - Evidence: `tests/hooks/test_pre_push.py` is currently red because it points to missing `scripts/hooks/pre-push.sh`.
   - Impact: the plan should treat restoration of a runnable test baseline as a prerequisite, not as existing coverage.

5. MINOR — Multi-ref pushes are not covered.
   - Evidence: the live hook buffers multiple stdin lines but classifies only from the first line.
   - Impact: a scope-aware rewrite could still misclassify multi-ref pushes unless tested.

## Required changes before plan-review

- Make hook installation worktree-aware using the real git/common hooks topology or a documented `core.hooksPath` strategy.
- Define the full pre-push chain contract explicitly, including which gates remain and in what order.
- Replace vague zero-remote pseudocode with an exact first-push diff/classification algorithm.
- Call out `tests/hooks/test_pre_push.py` as currently broken and require making it green.
- Add multi-ref push coverage.
