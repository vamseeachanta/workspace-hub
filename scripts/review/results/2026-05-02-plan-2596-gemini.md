### Verdict: MAJOR

### Summary
The erratum plan introduces a regression test that will falsely fail on itself and potentially other already-revised plans. Additionally, it appears to cite the wrong citation standard file based on the provided system context.

### Issues Found
- The regression test glob `docs/plans/2026-05-02-*.md` matches the W3-C erratum plan file itself (`2026-05-02-issue-2596-llm-wiki-W3C-2471-erratum.md`). The erratum plan mentions `#2471` heavily (e.g., in the title and frontmatter) without matching allowlist tokens within ±3 lines, guaranteeing a test failure on its own plan file.
- The plan relies on `.claude/rules/calc-citation-contract.md` as the authoritative frontmatter contract, but the system context defines `docs/standards/calc-output-citation.md` as the authoritative standard for verifying output citations. The plan may be hardcoding a Claude-specific rule path instead of the canonical workspace standard.
- The plan states it will 'Create' `tests/governance/test_2471_citation_scope.py`, but the attested evidence shows this file already EXISTS. The action should be 'Modify' or acknowledge the existing file.
- The new allowlist proximity check applies to all `2026-05-02-*.md` plans. It assumes W2-A and W2-B will pass because they are 'already revised', but those plans were written before this strict allowlist was designed and may not contain the exact required tokens (e.g., 'historical origin') within ±3 lines of their `#2471` mentions.

### Suggestions
- Exclude the erratum plan file itself from the glob in `test_2471_citation_scope.py` (e.g., filter out `*2596*erratum.md`), or ensure the erratum plan is written such that every #2471 mention is proximally covered by an allowlist token.
- Verify the correct standard path: replace references to `.claude/rules/calc-citation-contract.md` with `docs/standards/calc-output-citation.md` if the latter is the canonical documentation.
- Change the action for `tests/governance/test_2471_citation_scope.py` from 'Create' to 'Modify', or acknowledge its pre-existence.
