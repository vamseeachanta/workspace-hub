## Findings
1. `scripts/review/plan-review-fanout.sh:136` likely regresses Codex invocation: `codex exec - < "$combined_file"` is only tested against a mock and does not prove the installed Codex CLI treats `-` as stdin. If this CLI interprets `-` as the literal prompt, the review artifact can be empty, irrelevant, or `UNAVAILABLE`, recreating the post-reboot provider failure under a different shape.

2. `scripts/review/plan-review-fanout.sh:95` promotes stderr to the canonical artifact whenever stderr contains `^## Verdict`, even when `rc != 0`. A timed-out or killed provider can emit a partial structured header before `timeout` returns `124`; this code will promote the partial stderr review instead of recording an unavailable timeout. That is unsafe for both timeout behavior and structured-review promotion.

3. `scripts/review/tests/test_plan_review_fanout.sh:434` does not prove timeout/orphan behavior. The timeout test checks that an artifact contains `UNAVAILABLE`, but it does not assert the timeout exit reason, elapsed wall time, cleanup of child processes, or that a provider that ignores `TERM` is killed by `-k 5s`. It therefore does not cover the actual stall/orphan failure mode described in the issue.

## Required fixes
1. Verify the real installed Codex CLI stdin contract, or change invocation to a documented supported form. Add a focused smoke/regression test that would fail if `codex exec -` is treated as a literal prompt.

2. Only promote stderr structured reviews on successful provider exit, or require stronger validation for nonzero exits and never promote timeout/killed results. At minimum, `rc=124/137` should always produce an `UNAVAILABLE` timeout stub.

3. Strengthen timeout tests to prove bounded runtime and no surviving mock child process after timeout, including a mock that traps/ignores `TERM` long enough to exercise `timeout -k`.

## Residual risk
The hardening is directionally useful, but as written it may still silently lose Codex reviews or promote partial killed output as authoritative review signal.
