## MAJOR
- **BC1 — dirty scope `.claude scripts config` too broad.** Would STALE healthy machines on unrelated tracked edits (current tree already has unrelated `.claude/state` + `.claude/memory` mods). Replace with an explicit MEASURED-PATH allowlist (only what the collector reads: `.claude/skills`, `.claude/memory/context.md`, `.claude/dispatch`, `.claude/rules`, `.claude/hooks/plan-approval-gate.sh`, `.claude/settings.json`, `scripts/readiness/harness-config.yaml`, `config/scheduled-tasks/schedule-tasks.yaml`). Add NEGATIVE tests (unrelated `.claude/state/*`, other machines' equality reports, unrelated `.claude/memory/*` → NOT dirty).
- **BC2 — behind_main without fetch FALSE-NEGATIVES** the exact stale class being prevented: if local `origin/main` ref is itself stale, `behind_main` reads 0 while remote advanced → stale report enters comparison. "Runs after repo-sync pull" is not enforced/tested. Fix: record local-ref freshness (e.g. fetch-age from `.git/FETCH_HEAD`/`refs/remotes/origin/main` mtime); treat `origin_ref` unverified (fetch too old / ref absent) as STALE (fail-closed).
- **BC3 — unreachable-with-historical-report precedence.** `verdict_for` returns UNREACHABLE only when unreachable AND no report. An old valid report on an `status:unreachable` roster entry could render STALE/graded. Rule: roster `status:unreachable` must DOMINATE any present report. Add test.
